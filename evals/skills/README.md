## September 2026 refactor evidence

Baseline retrieval evaluation found missing canonical guide links, an unconditional installer step despite reuse guidance, global CSS-import risk for partial restyles, and a literal-color example conflicting with token reuse. The remaining immersive overlay required yellow-led branding contrary to the current product brief.

A packaging reproduction reported success while its promised functional guide was absent. Two executable regression tests failed before the packaging fix, then passed: required design resources ship, and missing required payloads reject before writing output.

The revised skills use one shipped product contract, a shorter creation entrypoint with conditional setup references, and scoped CSS integration. Source and packaged resource checks run via `scripts/check-repository.mjs`. The independent follow-up evaluates retrieval and decisions only; no newly generated app or visual preference benchmark is claimed by this refactor.

## October 2026 reference design and readiness evidence

Simulated, document-driven routing only, performed by the same agent session that wrote the guidance; no app was built, no independent agent was run and no Refero DESIGN.md was retrieved (the style page did not return its document). Five requests were traced through the revised entrypoints and references:

- **Landing page with an attached DESIGN.md:** `neon-create` (description names DESIGN.md landing pages) → reference design procedure → Blended by default → readiness: no forms or investment content, so Ship-ready checklist.
- **Back office screen with an attached DESIGN.md:** first trace found the reference procedure was linked only for campaign pages, so the functional scope rule could be missed. The link now covers any supplied DESIGN.md and the procedure's scope section limits it to section structure.
- **Fund campaign with return figures:** readiness flags investment content → disclaimer placeholder, Brand-ready, Handoff Summary.
- **shadcn on Tailwind v4 restyle:** `neon-redesign` fast path checks Tailwind/shadcn first → style migration format 5.
- **Rebuild onto the starter:** workflow contract row → scaffold rebuild section → new empty destination, original read-only.

Unverified: whether agents actually load these references at the right time, level fidelity on rendered pages, Brand Floor leakage in real output, whether the reference-design property groups match real Refero DESIGN.md sections, and the shadcn Tailwind v4 guidance beyond its check against the shadcn theming docs. The [reference design protocol](reference-design-protocol.md) and the scenario rows above are the next runs.
