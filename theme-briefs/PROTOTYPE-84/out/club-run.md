# Finnomena Club · Run — Theme Brief
> Running shoes on a white canvas — a shared start line, and every member invited to sign up

**Theme:** light
**Immersive Theme:** club

This is a Finnomena Theme Brief, not a Reference Design. Finnomena wrote it for one Campaign Page in the Club Immersive Theme. Colors and type come from the installed Neon theme and Immersive Themes CSS: the values below are for reading, never for retyping. Provisional pending design owner review.

Club opens the membership on a white canvas with navy ink and a navy main action. Light Grey steps build quiet section blocks, and Yellow marks the one moment on a screen that matters. It reads as Finnomena's everyday voice, dressed for a campaign. For race week the accent is held back for the start-line countdown and nothing else, so it lands like a starter's flag. The action stays steady on the join step, never competing with it. Rounded tint blocks follow one another like stages on a route, with generous gaps that keep the pace easy to read. The page ends on a row of laced shoes by the door the night before the gun. Membership ratio: White 60 / Light Grey 15 / Yellow 15 / Navy 10.

## Components

### Main Action
**Role:** The one primary action per section

Neon `Button` on `--immersive-action` with an `--immersive-on-action` label (18.12:1), headline type role, `--borderRadius-1000` corners, 48px high with `--space-4` side padding.

### Secondary Action
**Role:** An alternative beside the main action

Transparent fill with `--immersive-text` label and a 2px `--immersive-text` outline, the same height and radius as the Main Action.

### Logo
**Role:** Brand identity

Neon's logo item, the light-surface mark. Never recreate the wordmark as text.

### Tint Block
**Role:** Group a section or a set of details

`--immersive-palette-100` to `--immersive-palette-25` fills, each with its own `--immersive-on-palette-*` text. Flat: no border, no shadow; step lighter for nested emphasis.

### Accent Block
**Role:** The highlighted offer or call-out

`--immersive-accent-100` fill with `--immersive-on-accent-100` text. One per screen; lighter accent steps hold supporting copy.

### Race distance card
**Role:** One race distance to compare and pick

A var(--immersive-palette-50) fill carrying var(--immersive-on-palette-50) text, no border, var(--borderRadius-500) corners, var(--space-4) padding. The distance leads in title2, with start time, cut-off and member price as label2 lines, then one select action in var(--immersive-action) with var(--immersive-on-action) text. The picked card shows a 'Selected' caption.

### Route overview
**Role:** The course map and its checkpoints

A var(--immersive-palette-25) fill carrying var(--immersive-on-palette-25) text, no border, var(--borderRadius-500) corners, var(--space-4) padding. A labelled map image slot leads, followed by checkpoints as label1 distance markers with body names and water stations noted in caption. Never leave the map slot without its label.

### Race-day schedule
**Role:** The race-day timeline

A var(--immersive-palette-75) fill carrying var(--immersive-on-palette-75) text, no border, var(--borderRadius-500) corners, var(--space-4) padding. Each row pairs a label1 time with a body item and a label2 place, running from check-in through warm-up, start, finish and awards. Rows carry no actions.

### Registration call-out
**Role:** The single main registration action

A var(--immersive-accent-100) fill carrying var(--immersive-on-accent-100) text, no border, var(--borderRadius-500) corners, var(--space-4) padding. The registration deadline leads in title1, a body line explains the member benefit, and the main action follows in var(--immersive-action) with var(--immersive-on-action) text. Only one call-out per page.

## Do's and Don'ts

### Do
- Set `data-immersive-theme="club"` on the page root and color every section from its `--immersive-*` properties.
- Pair every fill with its own `--immersive-on-*` text color.
- Build emphasis with tint steps, never with opacity.
- Keep one color family per background block.
- Treat the canvas as its own color: it is not a palette step, so blocks may use `--immersive-palette-100`.
- Print the registration deadline beside every main action on each Race distance card and the Registration call-out, in var(--immersive-text).

### Don't
- Do not use gradients — Immersive Themes have none.
- Do not write new hex values or near-palette tints — every color is a token step.
- Do not let the shared secondary colors lead — keep them to small tags and illustration blocks.
- Do not use `--immersive-action` (Navy 100) as a block fill — it is reserved for the main action and its `--immersive-on-action` label.
- Do not use the route map as a decorative background — runners must read its turns and distances, so it belongs in the Route overview.

## Elevation

- **None.** The tokens define no shadow. Separate surfaces with tint steps, not shadows or borders.

## Imagery

Photography of members taking part leads the page. Frame it in close and mid shots that catch people mid-movement or mid-conversation, and leave generous space beside the subject so copy can sit there. Show real members and staff, candid and never posed stock, set against the light of the canvas so faces read clearly. In the hero, place the photo beside the Brand Pattern section, never over or under it, so the pattern stays whole. Use the theme's spot illustrations only for small explanatory blocks. Keep icons small, simple and secondary, so they label points instead of decorating. Keep imagery sparse: use at most one large image per screen, and keep supporting images small. Imagery never carries another brand's logo, copy or look, and IBM Plex Sans Thai and the Finnomena logo stay on every screen.

## Brand Pattern

- **Section:** hero
- **Colourway:** Yellow (`accent`)
- **Ground:** `--immersive-accent-50` with `--immersive-on-accent-50` text

The hero section carries the Brand Pattern. Its fill is the ground step, and the pattern's tones are other steps of the Yellow family only. The pattern comes from Finnomena's Block pattern generator with a locked seed and is committed as SVG; copy sits in its Text zone. Never crop, stretch, recolor, fade or hand-draw it, and never imitate it in CSS.

## Layout

A full-bleed page that opens on a split hero, which is also the Brand Pattern section: headline, supporting line and main action on one side, the lead image on the other, stacking image-last on narrow screens. Sections then alternate between open canvas and contained blocks with borderRadius-500 corners. The first detail-list sets each Race distance card on a block, the call-out holds the Registration call-out on canvas, the second detail-list pairs the Route overview and Race-day schedule on blocks, proof sits on canvas, and the form returns to a block. There is no navigation bar; a sticky main action appears on narrow screens after the hero. The footer is minimal: logo, organiser line and legal links. Rhythm stays comfortable, with space-10 between sections and space-4 inside cards.

## Motion

**Level:** subtle

Each section fades in and rises a short way once, as it first enters view, over 200–300ms with ease-out. Hover and focus transitions take 150ms. Nothing loops, autoplays or moves on its own. Under `prefers-reduced-motion: reduce`, use the still level.
