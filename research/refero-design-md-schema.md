# Refero Styles DESIGN.md: what a file contains

Survey of every DESIGN.md on [styles.refero.design](https://styles.refero.design), fetched 2026-11-01, and how the format maps onto Neon's four Immersive Themes.

## Corpus

- **Source:** 1,342 style pages listed in `https://styles.refero.design/sitemaps/styles.xml`. Each page displays its DESIGN.md as escaped text in a `<pre><code>` block; that displayed text is what was saved. It was not compared with the Download button output.
- **Fetch:** `/style/<id>` HTML only, one request per second, with `/api/` not touched. The site's `robots.txt` disallows `ClaudeBot`, `Claude-Web` and `anthropic-ai` by name; the `*` group allows `/style/`. The user chose the full fetch after being told this.
- **Result:** 1,342 of 1,342 extracted, each with `## Tokens — Colors`. Files are 172–578 lines (median 387).
- **Storage:** `research/refero/<brand>-<id8>.md`, plus `manifest.csv` (id, file, brand, theme, extract status) and `analysis.txt`. The folder is gitignored: it is third-party content and must not ship with Neon.
- **Reproduce:** `research/scripts/refero_fetch_all.sh <styles.xml> <raw-html-dir> research/refero research/scripts/refero_extract.py`, then `python3 -I research/scripts/refero_analyze.py research/refero`.

## Required content

Every file is generated from one template. The header is always:

```md
# <Brand> — Style Reference
> <one-line mood and metaphor>

**Theme:** light | dark | mixed

Source measurements are normalized; roles and recommendations are interpreted. …

<one paragraph: canvas, type voice, accents, geometry, overall metaphor>
```

Then up to 12 core sections. 521 files use exactly this sequence; the rest insert optional sections or promote Agent Prompt Guide subsections; only 1 file reorders the core:

| # | Section | Present | Must contain |
|---|---------|---------|--------------|
| 1 | Tokens — Colors | 100% | Table `Name \| Value \| Token \| Role`; 2–30 colors (median 9). Each role says where the color is used and why. |
| 2 | Tokens — Typography | 100% | One `### <Family> — <role> · \`--font-x\`` block per family (1–16, median 2), each with **Substitute**, **Weights**, **Sizes**, **Line height**, **Letter spacing** (89%), **Role**, and sometimes **OpenType features** (35%). Then `### Type Scale`: `Role \| Family \| Weight \| Size \| Line Height \| Letter Spacing \| Token`. |
| 3 | Tokens — Spacing & Shapes | 100% | **Base unit** (78%; 4px 721, 8px 267, 6px 55), **Density** (comfortable 910, compact 303, spacious 129). `### Spacing Scale` (`Name \| Value \| Token`), `### Border Radius` (`Element \| Value`, per element), `### Shadows` (41%), `### Layout` with **Page max-width** (81%), **Section gap**, **Card padding**, **Element gap**. |
| 4 | Components | 100% | 4–17 `###` entries (median 12), each `**Role:**` plus one paragraph of fill, text, radius, padding, type and border with exact values. Most common: buttons, cards, nav, pills, hero, links, badges, logo, footer, tags, inputs. |
| 5 | Do's and Don'ts | 100% | `### Do` and `### Don't`, about 7 bullets each; every bullet names an exact value. |
| 6 | Surfaces | 98% | Table `Level \| Name \| Value \| Purpose`, canvas first. |
| 7 | Elevation | 93% | Shadow recipes by use, or a statement that the system is flat. |
| 8 | Imagery | 100% | Prose: photography, illustration, icon style and density. |
| 9 | Layout | 96% | Prose: page width, hero pattern, section rhythm, nav and footer. |
| 10 | Agent Prompt Guide | 100% | **Quick Color Reference** (text, background, border, accent, primary action) and **3–5 Example Component Prompts** with exact values. In 18% of files these two are promoted to `##` headings. |
| 11 | Similar Brands | 99% | 3–5 bullets: `**Brand** — what is shared`. |
| 12 | Quick Start | 100% | `### CSS Custom Properties` (`:root`) and `### Tailwind v4` (`@theme`) repeating every token. |

Optional sections sit between Agent Prompt Guide and Similar Brands. Only **Gradient System** is common (8%). The rest are each in under 3% of files: typography, color, elevation and motion "philosophy" sections, radius and border systems, signature moves.

### What Refero measures and what it interprets

- **Measured** from the live site: color values, font families, sizes, weights, line heights, letter spacing, spacing steps, radii, shadows, page width, and component frequency.
- **Interpreted:** color roles, the mood paragraph, Do's and Don'ts, Imagery, Layout, Similar Brands, prompts and the HTML-free component descriptions.

## Adaptation to the four Immersive Themes

Files: [club](neon-themes/club/DESIGN.md), [exclusive](neon-themes/exclusive/DESIGN.md), [private](neon-themes/private/DESIGN.md), [ultra](neon-themes/ultra/DESIGN.md). Generated by `research/scripts/build_theme_design_md.py <immersive-themes.json> theme/tokens/colors.json research/neon-themes`.

All 12 Refero sections are kept, in Refero's order. Where each comes from:

| Refero section | Neon source |
|----------------|-------------|
| Header, Theme | Theme label; Ultra is `dark`, the others `light`. The membership ratio from the guideline ends the mood paragraph. |
| Tokens — Colors | Immersive Theme (`immersive-themes.json`) steps resolved through `theme/tokens/colors.json`, named by `--immersive-*` property, plus the shared secondary table. |
| Tokens — Typography | `theme/cds/theme.config.ts`: IBM Plex Sans Thai only, the 8 roles with Finnomena values. Substitute is "none" because the typeface is part of the Brand Floor. |
| Spacing & Shapes | `space` and `borderRadius` from `theme.config.ts`; button and tag radii from `theme/tokens/button.json` and `components.json`. |
| Components | Main and secondary action, tint block, accent block, support block (Ultra), highlight tag, hero and logo, from `skills/INSTRUCTION.md` immersive rules. |
| Do's and Don'ts | Guideline rules from INSTRUCTION.md and ADR 0004: White or Navy text, tints by step, one family per block, no gradients, canvas-step rule. |
| Surfaces, Elevation | Canvas then tint steps; no shadow, because the tokens define none. |
| Imagery, Layout | Interpreted from INSTRUCTION.md; labeled as such. |
| Agent Prompt Guide | Prompts written against `--immersive-*` properties, not raw hex. |
| Similar Brands | Replaced by **Sibling Themes**, the other three themes. Comparing Finnomena to outside brands would be invented. |
| Quick Start | The theme's `--immersive-*` block for reference, a pointer to the CSS adapter variables, and a Tailwind v4 `@theme inline` alias layer. Copy the generated CSS rather than retyping values. |

### Checks

- Every hex was looked up with `node scripts/token-lookup.mjs`: all are `colors.json` steps.
- Every fill and text pair was checked with `node scripts/contrast.mjs`. All 64 pass; the lowest are Red.100 with Navy (4.71:1), Purple.100 with White (4.80:1) and Ultra Navy.50 with Navy (5.22:1).

### Gaps and dependencies

- **Unmerged source.** The theme file `immersive-themes.json`, its generated `immersive-themes.css` and ADR 0004 exist only as uncommitted work in the `neon-skill-showcase` worktree. These files are drafts until that work lands.
- **Provisional.** The themes await design owner review, and every file says so.
- **Not in our tokens:** letter spacing, page max-width, shadows, and a card radius. The files say so instead of measuring a site. Section gap, card padding and card radius are labeled as interpreted.
- **Not wired into skills.** `skills/neon-audit/references/reference-design.md` treats a Refero file as outside reference input. These files describe Finnomena's own themes, so a skill would read them differently. Shipping them under `skills/` or `theme/` needs a decision, `node scripts/validate.mjs` and a regression case.
