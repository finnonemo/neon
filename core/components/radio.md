# Radio

> Core's Radio, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

Checkbox's tree (checkbox.md), same sizing, padding, gaps and bindings, with three differences: `Radio button margin` for `Checkbox margin` (Carbon's name), the glyph, and a round Focus ring.

   │  │     ├─ Icon                  `circle` (fa-sharp fa-regular/Large) · `circle-dot` (fa-sharp fa-solid/Large);
   │  │     │                        icon-primary (Disabled icon-disabled)

No `_` Items, no Slots, no nested instances.

## Icon records

`Radio/Icon/Large/Type token = fa-sharp fa-solid/Large` (ADR 0006), new. The glyph is the whole indicator: `circle` (Unselected, `fa-sharp fa-regular/Large`), `circle-dot` (Selected, solid: a thick ring around a hole, Base's selected look), always shown in the 24 × 24 Box, so the swap doesn't move the text.

## Text styles, wrapping and truncation

As Checkbox: `Label` `$subhead` one line; `Value` `$body`, Full-bleed wraps, Inset hugs one line; `Subtitle` `$subhead` wraps; `Icon` the FA step. Nothing is truncated.

## Hit target and Skeleton

- **Hit target**: `Interactive/Medium`, 48 × 48 minimum; `componentSet.interactive: true`, `hitTargetLayer: Container › Icon + Value` (ADR 0003, 2026-11-02 amendment). Icon only is the glyph centred in a 48 × 48 row.
- **Skeleton**: Carbon's: the glyph keeps its Selection; `Text` gives way to the 80 × 8 bar; Icon only's Skeleton is the glyph alone.

## Accessibility

As Checkbox, items 1–8 (checkbox.md); Selection is shape (an empty ring, a ring around a hole). Item 9:

|  | Web |
| --- | --- |
| Role | `role="radio"` (or `<input type="radio">`) in a `radiogroup` |
| Accessible name | `<label for>`, `aria-describedby` the Subtitle |
| Announced states | `aria-checked`, `aria-disabled` |
| Focus order | Tab enters the group at the selected radio (or the first), arrow keys move between options |

On Inset, the group `Label` names the radio group (`radiogroup`'s label on web, a header trait on iOS).

## Usage

22 instances moved onto the new set on 2026-11-02, as Checkbox's did; none of the old set's is left:

- `Style=Default` → `Type=Full-bleed, Alignment=Left`, same State and Selection, `Label text` → `Value text`, the old `Subtitle` boolean → `Description`, the instance's sizing kept (Fill), `Bottom border` on. Ten, in Radio buttons › Usage (Group, Long label and Focus ring, Light and Dark).
- `Style=Radio only` → `Type=Icon only, Alignment=Left`, same State and Selection (none of them was Pressed, which Icon only lacks). The three `1602:*` came after the proposal's count of 19.
- The two Focus ring samples stay `State=Enabled` inside their hand-drawn ring; `State=Focus` now draws the ring itself, so they could move onto it.
