# Tile

> Core's Tile, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

Base's two rows inside Carbon's padded `Content`, with Tile's own Label block and a Slot:

```

├─ Container                     VERTICAL, Fill × Hug, min width and min height 80 (Inline 48), gap 0, radius 16, clips; fill 0 layer-01 (Action, Toggle row: layer-02), fill 1 Transparent

│  └─ Content                    VERTICAL, Fill × Hug, padding 16 (Inline: 12 top and bottom), gap 16
│     ├─ Content top             HORIZONTAL, Fill × Hug, top-aligned: space between; right-aligned with Leading None;

│     │  ├─ Content leading      hidden with Leading None. Artwork medium 24 box (Icon/Large), Artwork large 36 box
│     │  │  │                    (Icon/2XLarge); Hug round Artwork custom; Fill for Label. Glyph boxes take
│     │  │  │                    skeleton-background in Skeleton
│     │  │  ├─ Icon              TEXT glyph, fa-sharp fa-solid/Large or /2XLarge, icon-primary; hidden in Skeleton

│     │     │                    Radio; the Toggle Item's size for Toggle; Artwork/Thumbnail (40 × 28) for

│     │     │                    border-subtle
│     │     ├─ Toggle            Toggle Style=Toggle only, absolute at y −10; iOS from the tile's iOS, Toggled from
│     │     │                    Selected, State Enabled (Skeleton: Skeleton)
│     │     ├─ Radio             Type=Icon only, absolute, centred on the box (x −12, y −12)
│     │     └─ Checkbox          the same; both: Selection from Selected, State Enabled (Skeleton: Skeleton)
│     ├─ Content bottom          VERTICAL, Fill × Hug, gap 0 (the Label block); hidden on Inline and in Skeleton
│     │  ├─ Title                Headings/Headline (17/24 Medium), text-primary, wraps
│     │  └─ Description          Body/Subheadline, text-secondary, wraps (BOOLEAN `Description`, on)

│     │  └─ Title line           80 × 8, radius 0, skeleton-background
│     └─ Slot                    SLOT, Fill × Hug: a Tag, Value, Progress steps, a Button (SLOT `Slot`, shown by BOOLEAN `Show Slot`, off)
└─ Focus ring                    State=Focus only: absolute at −4 on every side, stroke 2 inside Focus/focus,
                                 radius 20, no fill
```

- `Content top`, `Content leading`, `Content trailing` and `Content bottom` are Base's names; `Title` and `Description` are Carbon Tile's; the bars follow List item's `Label line`.
- `Content bottom` and `Skeleton` › `Title line` follow the Label block rule: gap 0. The spec declares `labelBlock` on them.
- The indicator's and the Toggle's 48 Roots are absolute in their box, so `Content top` stays 24 tall (28 on the Toggle rows) and the control sits on the padding line at the top right.
- No `_` Items. Slot: `Slot` (a frame after a build: the owner converts it to a SLOT by hand; the spec lists it, so a rebuild keeps it). Nested public instances: Radio, Checkbox, Toggle and Badge, kept in every variant and hidden unless `Trailing content` shows them.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Behavior` | Selection · Action | Selection is picked (`Selected`); Action opens something |
| `Leading content` | None · Artwork medium · Artwork large · Artwork custom · Label | the `Content leading` part and `Content top`'s alignment |
| `Trailing content` | None · Label · Badge · Chevron · Thumbnail · Toggle · Checkbox · Radio | the `Content trailing` part. `Check` became `Checkbox`, as on List item; `Thumbnail` a trailing image |
| `State` | Enabled · Active · Focus · Skeleton | Active: the Container's second fill; Focus: the `Focus ring`; Skeleton: the bars, the grey artwork, the controls' own Skeleton |
| `Selected` | Off · On | the Container stroke; the Radio's and Checkbox's `Selection`, the Toggle's `Toggled` |
| `Layout` | Stacked · Inline | Stacked: the parts above the Label block; Inline: one row, the labels in `Content top` beside the leading part |

Excluded:

- On `Behavior=Selection`: Chevron, Thumbnail.
- `Trailing content=Thumbnail` with `Leading content=Artwork custom` (two images in one row).
- On `Behavior=Action`: Toggle, Checkbox, Radio, and `Selected=On`.
- `Selected=On` with Skeleton.
- On `Layout=Inline`: `Leading content=Label`; `Trailing content=Label`, `Checkbox`, `Radio`.

Action 4 × 4 = 16. 65 × 5 columns = **325** `Stacked`; `Inline` per column but Label: Selection None · Badge · Toggle = 28 + Action None · Badge · Chevron × 4 = 12, 40 × 4 = 160; Thumbnail on Action: Stacked 4 columns (not Artwork custom) × 4 States = 16, Inline 3 × 4 = 12; **513 variants**.

Properties: TEXT `Title text`, `Description text`, `Leading label text`, `Trailing label text`, `Trailing description text`; BOOLEAN `Description` (on), `Trailing description` (on), `Show Slot` (off); SLOT `Slot`. The glyph is the `Icon` layer's text and the artwork is `Artwork`'s image fill, not instance swaps.

Grid: columns `Leading content`; rows `Layout`, `Behavior`, `Trailing content`, `iOS`, `Selected`, `State` innermost. Grid order puts `iOS` in columns, but here it exists on one trailing value only: a column split would leave half the grid empty, and `componentSet.grid` needs every row full. grid-audit's "iOS not the innermost column" flag on this set is expected.

## Hit target and Skeleton

- **Hit target**: `Interactive/Medium` (48) min width and height on the Root in every variant (`componentSet.interactive: true`, no `hitTargetLayer`). The smallest tile is 56 tall, so the binding never grows it. The whole tile is the one target (Q9, "Tile กดได้ทั้งการ์ด"): the nested controls keep their 48 Roots but take no tap of their own and are hidden from assistive tech, so a tile is one focus stop.
- **Skeleton**: `Content bottom` hides and `Skeleton` shows its bar; a Label part shows its own bar; glyph boxes and Artwork custom take `skeleton-background` and their contents hide; Badge and Chevron hide; Toggle, Radio and Checkbox take their own `State=Skeleton`. `Slot` content keeps its own state.

## Usage

- A plan picker, `Behavior=Selection`, `Trailing content=Radio`: `ลงทุนรายเดือน` / `ตัดเงินอัตโนมัติทุกวันที่ 25` selected, `ลงทุนครั้งเดียว` / `จ่ายครั้งเดียวผ่านบัญชีธนาคาร` beside it.
- A fund pick, `Trailing content=Checkbox`, `Leading content=Artwork medium`: `กองทุนหุ้นไทย` / `ความเสี่ยงระดับ 6` and `กองทุนตราสารหนี้` / `ความเสี่ยงระดับ 4`, one selected.
- A content tile, `Behavior=Action`, `Leading content=Artwork custom`, that opens an article.
- A document row, `Layout=Inline`, `Leading content=Artwork medium` (`file-invoice`), `Trailing content=Thumbnail`: `หนังสือชี้ชวนกองทุน` / `อัปเดตล่าสุด 1 พ.ย. 2569`, in `Action rows`.
- Skeleton tiles; `State=Focus` once, on a selected tile.
- Not yet drawn: a tile with a Toggle, a trailing Label (an amount), a Badge, a Chevron; a neutral tile with a CTA (a Button in `Slot`).
- Not for one-line options (bank accounts, settings): List item with a trailing Radio or Checkbox. Not for a status message: Contextual banner. Not a container of rows: stack List items on the page. A tile with a control in `Slot` is never `Behavior=Selection` (two targets in one); Figma can't stop it, so review checks it.
