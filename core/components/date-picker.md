# Date picker

> Core's Date picker, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

```
Date picker (variant root)      Fill × Hug in a Fixed set (fill: true); the base is Fixed 370 × Hug, no fill, no padding
└─ Container                    VERTICAL, Fill × Hug, gap Container/Default/Gap vertical (4)
   ├─ Fields                    HORIZONTAL, Fill × Hug, gap Container/Default/Gap horizontal (8)
   │  ├─ Date field             Date field, exposed; Single only; Fill × Hug; Size from the variant
   │  ├─ Start date             Date field, exposed, Title "Start date"; Range only; Fill × Hug
   │  └─ End date               Date field, exposed, Title "End date"; Range only; Fill × Hug
   └─ Calendar                  Pickers `Style=Compact iOS=False`, Mode Date (Single) or Range (Range); Open only; 370 wide
```

The base holds all three fields and the calendar; the spec's `visible` rules pick them per variant. Each field is `Helper=true, Text filled=False, State=Enabled, Size=Large` in the base; the calendar `Show Week 6=false`.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Type` | Single · Range | one Date field, or Start date and End date; the calendar's `Mode` Date or Range |
| `Open` | False · True | the calendar shown under the fields |
| `Size` | Large · Medium · Small | the fields' `Size` (56 · 48 · 36); the calendar is the same at every Size |

Properties: none of its own; State, value and text are set on each exposed Date field. 2 × 2 × 3 = **12 variants**.

## Component variables and Theme tokens

Two new `Components` variables, Tag's shape; nothing varies by Size, so the key is `Default` (Accordion's). The Fields row binds Container's horizontal gap, as Progress steps binds it on its Steps row (Tag's groups have no `Fields`).

| Group | Keyed by | Properties | Values |
| --- | --- | --- | --- |
| `Container` | `Default` | `Gap vertical` | `Spacing/spacing-02` (4) |
| `Container` | `Default` | `Gap horizontal` | `Spacing/spacing-03` (8) |

No `Theme` token of its own: the set paints nothing. The fields and the calendar bind their own (date-field.md, date-and-time.md), so the spec's `contrast` list is empty.

## Icon records

None of its own: the Date field's calendar icon and the Pickers' arrows are theirs.

## Text styles, wrapping and truncation

None of its own: each field's text is Date field's, the calendar's is Pickers'. On Range each field is 181 wide; its value "17/11/2026" fits at every Size, and Date field truncates its input `ENDING` as Text field.

## Hit target and Skeleton

- **Hit target**: None: not interactive. The fields, the calendar's days and its arrows bring their own.
- **Skeleton**: None as an axis: a field takes its own `State=Skeleton`; the calendar has none (Pickers').

## Usage

- A date picked from a month on Android and web: Date picker, Single. A date range (a statement period): Range. A date typed where the person knows it: [Date field](date-field.md) alone.
- Not on iOS: use Date and time - Collapsed.
- Samples on Date and time pickers, Light and Dark, after "Compact open, iOS=False": Single "วันที่นัดหมาย" 17/11/2569 with the helper "วัน/เดือน/ปี พ.ศ."; Range "วันเริ่มต้น" 17/11/2569 and "วันสิ้นสุด" 24/11/2569, helper off; both open on "พฤศจิกายน 2569", weekdays อา … ส.
