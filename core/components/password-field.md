## Anatomy and layer tree

Text field's tree ([text-field.md](text-field.md)) without `_Unit suffix`. `Input text` shows `●●●●●●●●` or, with `Show text`, the value; `Eye`, an Icons instance (`eye` · `eye-slash`), is last in `Field`, after `Status`, with no target of its own (owner, 2026-11-02).

## Component variables and Theme tokens

Text field's: the spec sets `variablePrefix: 'Text field'` and binds the same `Components/Text field/Field/<Size>/*` and `Text field/Icon/<Step>/*` variables and the same Semantic `Theme` tokens per state ([text-field.md](text-field.md)). No `Password field/*` variables: the two sets look the same, so a change to one reaches both. Its one binding of its own is the Disabled eye, `Theme/Icon/icon-disabled`.

## Usage

- Use for a password, PIN entered as text, or any secret value. A one-time code in boxes is PIN code, not this.
- `Show text=True` for the revealed state; the eye-slash follows.
- No unit: a secret has none. An amount is a Text field with `Unit` on.
