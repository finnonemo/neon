# Table

> Core's Table, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

```
Table (plain component, axes [])     Fixed 375 × Hug (an `axes: []` build keeps its base's width); a designer sets an instance Fill; no fill, no padding
└─ Rows                              SLOT `Rows`; Vertical, Fill × Hug, gap 0
   ├─ Table row  Type=Header         default content (Decision 12)
   └─ Table row  Type=Body  ×4

Table row (variant root)             Horizontal, Fill × Hug; fill: Header `layer-02`, Body Hover `layer-hover-01`, else none
├─ Background                        absolute, pinned to all four edges, `layer-02`; BOOLEAN `Zebra` (Body only)
├─ Selected                          absolute, `layer-selected-01`; BOOLEAN `Selected` (Body only)
├─ Margin left                       8 (Container Padding left) × Fill; BOOLEAN `Margins`
├─ Leading                           Hug, min 48 × 48; Expand (Icon button), Checkbox, Radio by `Expansion` and `Selection`
├─ Cells                             SLOT `Cells`; Horizontal, Fill × Hug, min height by Size, padding 0, gap 0
│  └─ Table cell / Table header cell ×4   default content, each Fill and the row's Size, Medium (Decisions 10, 12)
├─ Margin right                      8 (Container Padding right) × Fill; BOOLEAN `Margins`

Table expanded row (plain component)  Fixed 375 × Hug, padding `spacing-05` left / right / bottom
├─ Content                           SLOT `Content`; Fill × Hug; a `$body` `text-secondary` paragraph, left-aligned

Table cell (variant root)            Fill × Hug, min height by Size; Focus: `Focus/focus` stroke 2 inside
└─ Container                         Horizontal, Fill × Hug, padding by Size (Control on Number · Button · Input), gap `spacing-03`; align by `Alignment` and `Vertical alignment`
   ├─ Leading                        frame, Hug; Avatar 2XSmall (Avatar) or an FA glyph (Icon; Text with `Show Leading`), exposed
   ├─ Text                           Vertical, Fill × Hug, gap 0; BOOLEAN `Text` (Text · Badge · Avatar · Icon)
   │  ├─ Label                       `$body`, `text-primary`; TEXT `Label`
   │  └─ Second line                 `$footnote`, `text-secondary`; BOOLEAN `Second line` (Medium · Large), TEXT `Second line text`
   └─ Trailing                       frame, Hug (Fill on Number · Input); Display tag, Value, Badge, Button or Text field by Type, exposed; BOOLEAN `Show Trailing` (Text)

Table header cell (variant root)     Fill × Hug, min height by Size; Focus as Table cell
└─ Container                         Horizontal, Fill × Hug, padding by Size, gap `spacing-02`; align by `Alignment`
   ├─ Label                          `$footnote` Strong, `text-secondary`; TEXT `Label`
   └─ Icon                           Small, fixed 20 wide, `icon-secondary`; shows when `Sortable` or Sorted ≠ None
```

- **Row padding, not cell padding, holds the edge.** The cells pad 8 a side (`spacing-03`), so two columns' text sits 16 apart, as Carbon's 16. The row pads 8 more, so the first and last text sit 16 from the table's edge, and the Hover, Zebra and Header fills run edge to edge.
- **Slots own their content.** Figma refuses to expose an instance inside a Slot (Tabs, figma-instances.md), so a designer selects a row or cell in the Slot to set it. A Slot's content isn't pinned by its parent's variant (Variant axes), so each row and cell carries its own `Size` (Decision 10).
- **Column widths** are the designer's: cells Fill, and a column that must not share space (a date, a figure) is set Fixed on each of its cells by hand (Decision 2). There is no column object to set it once; Uber's plugin does it for them, we don't have one.
- **Table expanded row has no `Container`**: its root holds the padding and the `Content` Slot, so `structure-check.js` flags `container` on it, accepted (the owner, 2026-11-07). A Container would move the Slot and the content placed instances hold in it.

## Icon records

`Table header cell/Icon/Small/Type token = fa-sharp fa-solid/Small`: beside the `$footnote` label (13 pt), the Small step. Glyphs: `arrow-up-arrow-down` (Sortable, Sorted = None), `arrow-up` (Ascending), `arrow-down` (Descending). The Icon layer is fixed 20 wide, so a glyph swap doesn't move the label. Table cell has no icon; an icon in a cell goes in its Slot.

## Hit target and Skeleton

- **Hit target**: none on `Table`, `Table row` and `Table cell` (`interactive: false`): nobody taps them, and a tapped row is [List item](list-item.md). A cell's Focus is keyboard focus on the web grid, not a tap. `Table header cell` is `interactive: true` (a `Sortable` one is tapped): its Root binds `Interactive/<Size>/Interactive min-height` (ADR 0003), which at 48 · 56 · 72 doesn't change its height.
- **Skeleton**: `Table cell` and `Table row` have none yet (Decision 7). `Table toolbar` and [Pagination](pagination.md) got `State=Skeleton` in #659;

## Usage

- A Table: Header row, then Body rows, all one Size. Thai copy.
- Figures right-aligned (`Alignment=Right`, header too); text left.
- At 375, two to four columns; more scrolls sideways.
- Zebra on long tables of figures, or Divider, not both.
- Not for one term and its value down the screen, or a tapped row: that is [List item](list-item.md) (Detail row, deprecated 2026-11-09).
