# Stepper

> Core's Stepper, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

Select's tree (structure.md, reading (a)), with Text field's input in the Field and the Chevron replaced by `Actions`.

```
Stepper (variant root)             Fill × Hug, no fill, no padding, no min size (call 7)
└─ Container                       VERTICAL, Fill × Hug, gap 8 (raw, as Select)
   ├─ Label                        HORIZONTAL, Fill × Hug
   │  ├─ Title                     TEXT, Fill (hidden on Skeleton)
   │  └─ Skeleton title            120 × 16, radius 4 (Skeleton only)
   ├─ Field                        HORIZONTAL, Fill × Hug, min height Stepper/Field/<Size>/Layout min-height, centred,
   │  │                            padding 16 / 0 (right: call 8), gap 16, radius 8, stroke 3 (Read-only 2), no clip
   │  ├─ Text overflow             Fill × Hug, padding 0, gap 0, wraps (hidden on Skeleton)
   │  │  ├─ Input text             TEXT, Hug, one line, never cut (a figure)
   │  │  ├─ Input cursor           Utility instance, Active · Error · Success (call 5)
   │  │  └─ _Unit suffix           instance, shown by the `Unit` boolean; State pinned Enabled | Disabled (call 9)
   │  ├─ Status                    Incomplete · Warning · Complete glyph, or `_Loading`
   │  └─ Actions                   HORIZONTAL, Hug × Fixed (height = Field min height), gap 0, centred, no clip;
   │     │                         hidden on Read-only and Skeleton
   │     ├─ Decrement              Icon button, exposed: Tertiary · Default · iOS=False, `Icon Text` minus
   │     └─ Increment              Icon button, exposed: Tertiary · Default · iOS=False, `Icon Text` plus
   └─ Detail                       HORIZONTAL, gap 4 (raw), hidden on Skeleton
      └─ Helper Text | Error message | Success message | Warning message, with its glyph on Error / Success
```

- **Minus, then plus**, side by side at the trailing edge, as Carbon's Number input and Base's `Stepper` control (call 1).
- **The buttons are Icon button instances**, not a new Item. They bring their own 48 target, pressed fill, Focus ring and Disabled look. The owner deleted `_Text field action` on 2026-11-02, so the field family has no action Item to reuse, and Icon button already draws every state the buttons need.
- **`Actions` has a fixed height**, bound to the Field's min height. On Small, the two 48 roots overflow the 36 Field by 6 above and below, and nothing clips (call 4).
- **Exposed**: a designer sets `State=Disabled` on Decrement at the minimum and on Increment at the maximum (call 3), and `State=Active` to show one pressed.
- The Input text and Input cursor follow Text field's (`Input text` Hug, the cursor after it).
- **`Text overflow` wraps** (`layoutWrap`, row gap 0, set on the base): when the figure and unit outgrow it at large text sizes, the unit drops under the figure and still follows it (ADR 0010), instead of running under the buttons.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `State` | Enabled · Pressed · Focus · Active · Error · Success · Incomplete · Warning · Complete · Read-only · Loading · Disabled · Skeleton | fill, stroke, the cursor, the Status glyph, the Detail line, the buttons' pinned `State`, whether `Actions` shows |
| `Size` | Large · Medium · Small | Field min height 56 / 48 / 36, text styles, the buttons' `Size`, icon steps |

Properties: `Unit` (BOOLEAN, default False) shows `_Unit suffix`, linked in the 36 non-Skeleton variants (call 9). The buttons are exposed nested instances, not properties. 13 × 3 = **39 variants** with every call as recommended. Without Warning (call 6): 36. With a `Limit` axis (call 3, b): 13 × 3 × 3 = 117. With Large · Medium only (call 4, c): 26.

What each `State` pins on the buttons:

| Host `State` | Decrement · Increment |
| --- | --- |
| Enabled · Pressed · Focus · Active · Error · Success · Incomplete · Warning · Complete · Loading | `State=Enabled` |
| Disabled | `State=Disabled` |
| Read-only · Skeleton | hidden (`Actions` off) |

- Host `Pressed` is a press on the field itself, which focuses it to type. It doesn't press a button: a pressed button is `State=Active` on that instance.
- Host `Focus` is the field focused before typing, `Active` is typing (cursor), as Text field.

## Component variables and Theme tokens

`Components`, Tag's three-level shape. The values alias the same steps as Select's and Text field's (architecture.md, Existing components: "No component aliases another component's variables"). The only step that differs is `Padding right` (call 8).

| Group | Keyed by | Properties | Values |
| --- | --- | --- | --- |
| `Stepper/Field/<Size>` | `Size` | Layout horizontal, Layout vertical | `Fill container`, `Hug contents` |
|  |  | Layout min-height | `Sizing/control-large` · `control-medium` · `control-small` (56 · 48 · 36) |
|  |  | Padding left | `Spacing/spacing-05` (16) |
|  |  | Padding right | `Spacing/spacing-00` (call 8; Select's is `spacing-05`) |

|  |  | Radius | `Radius/8px (radius-sm)` |

10 × 3 + 2 = **32 variables**, all new; none in `Theme`. `Actions`' height binds `Stepper/Field/<Size>/Layout min-height` too, so nothing is added for it. The buttons' sizes are Icon button's own (`Icon button/Container/<Size>`), chosen by the pinned `Size`, so Stepper has no button variables.

- **The buttons bind nothing of Stepper's.** Icon button's own rules give the glyph (`icon-primary`, `icon-disabled`), the pressed fill (`Button/button-secondary-active`, Navy/15A · White/15A since 2026-11-02) and the Focus ring. Carbon's `layer-active-01` (Navy/8A · White/12A) and `icon-on-color-disabled` map to those, so no Stepper rule overrides a nested button.
- The pressed fill over `Field/field` (Navy/10A · White/10A) is faint. It is decorative: the glyph and the value change carry the press. On the white fills (Active, Error, Success) it reads clearly.
- No divider between the buttons (Assumptions).

Pairs (the spec's `contrast` list):

- Text: Title and the Detail lines on the Base surfaces; Input text and the unit on `Field`, grey and white.
- Non-text: each button's glyph (`Icon/icon-primary`) on `Field/field` and on `Background/background-primary`; the Status glyphs on `Field`; the Error / Success Detail glyphs on the surfaces; the Focus / Active / Error / Success stroke.
- Decorative: Read-only's stroke, the fill, the buttons' pressed fill.
- The Focus ring.

## Icon records

`Stepper/Icon/<Step>/Type token = fa-sharp fa-solid/<Step>`, for the Status glyphs. Beside text the step follows the value text (Icons): Large → Large (17), Medium and Small → Medium (15), as Select. The Detail glyphs are Medium at every Size (beside Subheadline). `_Loading` is Medium on Large, Small otherwise.

The buttons' glyphs are Icon button's, set by the `Size` each Stepper `Size` pins:

| Stepper `Size` | Field | Icon button `Size` | Drawn box (pressed fill) | Glyph |
| --- | --- | --- | --- | --- |
| Large | 56 | Medium | 48, 4 from the Field's top and bottom | 17 (`fa-sharp fa-solid/Large`, as the value's step) |
| Medium | 48 | Small | 36, 6 from each edge | 15 (`/Medium`, as the value's step) |
| Small | 36 | XSmall | 28, 4 from each edge | 13 (`/Small`, one step under the value's 15) |

`minus` and `plus` are Font Awesome glyphs set through the Icons instance's `Icon Text` (structure.md on PR #206, "Icons" and check 12). Nothing is drawn as a vector. The glyphs never swap, so no fixed-width icon layer is needed.

## Text styles, wrapping and truncation

| Layer | Text style (Large · Medium · Small) | Lines | Text property |
| --- | --- | --- | --- |
| `Title` | `Headings/Headline` · `Body/Callout` · `Body/Subheadline` | wraps (auto height) | none yet |
| `Input text` | `Body/Body` · `Body/Callout` · `Body/Subheadline` | one line: Hug, auto width, no truncation, since a figure is never cut (Localisation) | none yet |
| `_Unit suffix` › `Unit` | as Input text | one line, never cut | the Utility's `Unit` |
| `Helper Text` · `Error message` · `Success message` · `Warning message` | `Body/Subheadline` | wraps, never truncates | none yet |

- `Input text` is Hug like Text field's, so the cursor follows the last digit. It is not Fill and `ENDING` like Select's `Value text`: a stepped figure is short, and cutting a figure would hide what it is.
- A Hug text runs under a trailing control when it outgrows the Field. The reflow check therefore uses the longest figure a Usage case shows (`1,000,000` with the `Units` suffix), 343 wide. `Text overflow` wraps so the unit drops under the figure;
- The `Input cursor` has no Callout class, so Text field pins `Body` at every Size. Stepper does the same.

## Hit target and Skeleton

- **Hit target**: each button is a nested Icon button with its own 48 Root (ADR 0003: "A nested control brings its own"). On Small the two 48 roots overflow the 36 Field by 6 above and below, and the Field, `Actions` and Container don't clip (call 4). The field itself takes the tap to type, as Text field, and has no Root target of its own (call 7).
- **Skeleton**: `State=Skeleton`, as Text field and Carbon's Number input: the Field in `skeleton-background`, the 120 × 16 Title bar, and no value, buttons or Detail. Carbon keeps its buttons on Skeleton, and Select drops its chevron. Stepper follows Select (Assumptions).

## Motion

| Transition | Token | Reduced form | Haptic |
| --- | --- | --- | --- |
| Stroke on Focus / Active / Error / Success | `fast-01 · standard` | kept | None |
| Field pressed fill | `fast-01 · standard` | kept (colour only) | None |
| A button's pressed fill | Icon button's own | Icon button's | None |
| The value stepping | none: the new figure replaces the old at once | instant | None |
| Skeleton | the Skeleton's own | static shape, no shimmer | None |

Stepping fires no haptic (Motion and haptics: `Selection` is Segmented control's only). Holding a button repeats the step at the platform's rate. That is behaviour, not a transition.

## Usage

- Small whole numbers with a known step: units of a fund, the number of instalments, a quantity. A money amount is an Amount field (Amount entry). A choice from a few values is a Segmented control or a Select.
- Thai copy in every case: Title "จำนวนหน่วย", helper "ขั้นต่ำ 1 หน่วย", unit `Units`.
- At the minimum, set Decrement to `State=Disabled`; at the maximum, Increment. A typed value outside the range is an Error with a message ("ต้องไม่เกิน 10 หน่วย"); it isn't clamped silently.
- The figure can be typed as well as stepped (call 5); the number pad opens on focus.
- Read-only for a value the user can't change in this form; Disabled only for "can't interact".
- The Focus ring once, outside the field.
