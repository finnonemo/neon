# Divider

> Core's Divider, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

```
Divider (variant root)          Fill × Hug, no fill, no padding, VERTICAL
└─ Container                    Fill × Hug, HORIZONTAL; Padding left keyed by Inset (0 · 16), the other paddings 0
   └─ Line                      Fill × Fixed, height 1 (Divider/Line/<Inset>/Layout height); fill Border/border-subtle
```

- No `_` Items, no Slots, no nested instances.
- The line is a filled 1-tall leaf, not a stroke. A stroke on Container would also run under the inset, and a frame can't take a 1-wide stroke on one side without a height of its own. So the AC's "stroke 1" is the Line's height of 1.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Inset` | None · Start | Container's `Padding left`: 0 · 16 (`spacing-05`, the side pad of List item) |

Properties: none. 1 axis of 2 values = **2 variants**.

## Component variables and Theme tokens

`Components`, Tag's three-level shape, keyed by `Inset`. Scale steps alias their step (Sizing and scales); the height of 1 is off the scale and stays raw.

| Group | Keyed by | Properties | Values |
| --- | --- | --- | --- |
| `Divider/Container` | `Inset` | `Padding left` | None `Spacing/spacing-00 = 0` · Start `Spacing/spacing-05 = 16` |
|  |  | `Padding right`, `Padding top`, `Padding bottom` | `Spacing/spacing-00 = 0` under both |
| `Divider/Line` | `Inset` | `Layout height` | 1 (raw) under both |

10 variables. `Line` is a new group word for the drawn line, as `Track` was for Toggle ([toggle.md](toggle.md)); the Element template has no word for it.

Templates: `Components/Divider/Container/{{Inset=*}}/<Property>`, `Components/Divider/Line/{{Inset=*}}/Layout height`.

`Theme`: no Component-scoped token, since no axis picks the colour. `Line`'s fill binds `Border/border-subtle` (Light `Black/5A`, Dark `White/15A`) directly.

| Theme token | Light | Dark | Paired with |
| --- | --- | --- | --- |
| `Border/border-subtle` (Semantic) | `Black/5A` | `White/15A` | decorative: no pair. The spec's `contrast` lists it as `decorative` on `Container › Line` |

## Usage

The `Usage` frame shows, with Thai copy:

- Between two groups of rows, full width (`Inset=None`): `บัญชีของฉัน` rows, a Divider, then `การตั้งค่า` rows. The rows are plain text until List item (pawisssh/design-system#157) is built.
- Under a row that starts at the side pad (`Inset=Start`), so the line starts where the text does.
- Don'ts: no Divider between the rows of one list (rows have no separator, Inventory); no Divider to separate surfaces, which separate by background (Tile).
- No Focus ring: not interactive. No `iOS` pair: one look.
