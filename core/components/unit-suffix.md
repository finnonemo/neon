# _Unit suffix

> Core's _Unit suffix, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

```
_Unit suffix (variant root)     Hug × Hug, no fill, no padding, HORIZONTAL
└─ Container                    Hug × Hug, HORIZONTAL, no fill
   └─ Unit                      TEXT, WIDTH_AND_HEIGHT, Body/Body on the main
```

The gap is a U+00A0 no-break space at the start of `Unit`'s characters, not padding, so it scales with whatever text style the host sets and matches what developers append in code.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Unit` | Baht · Units · Percent | `Unit` characters: ` ฿`, ` หน่วย`, `%` |
| `State` | Enabled · Disabled | `Unit` fill: `Unit suffix/<State>/text` |
| `Text style` | Body · Title 2 · Title 1 · Large Title | `Unit` text style: `Body/Body`, `Headings/Title 2`, `Headings/Title 1`, `Headings/Large Title` |

Properties: none (the designer never types the unit). 3 × 2 × 4 = **24 variants**. `Text style`, not `Size`: the build lint keeps `Size` for XSmall … XLarge. The grid's columns are `Text style`, largest first; its rows `Unit`, then `State`.

## Component variables and Theme tokens

No `Components` variables: the Utility binds no number. The gap is a character and the size is the host's text style.

| Theme token | Light | Dark | Paired with |
| --- | --- | --- | --- |
| `Text/text-secondary` (State=Enabled), bound directly | `Black/65A` | `White/65A` | the host's background |
| `Text/text-disabled` (State=Disabled), bound directly | `Black/45A` | `White/45A` | the host's background |

The `Unit suffix/Enabled/text` and `Unit suffix/Disabled/text` Theme tokens were removed on 2026-11-08 (owner, ios-carbon-map.md section 4): Theme holds no per-component tokens.

## Text styles, wrapping and truncation

| Layer | Text style | Lines | Text property |
| --- | --- | --- | --- |
| `Unit` | the `Text style` variant; on `Body`, a host may override it with its own style | one line, never truncates (part of a figure) | none |

**Following the host's style.** A host whose style is one of the `Text style` values picks that variant on its nested instance (a `componentProperties.Text style` rule in the host's spec), with no override: Amount field, one step under the digits. A host on another style stays on `Body` and sets `textStyleId` on its nested `_Unit suffix › Container › Unit`: Text field (the input's style), Value and Stepper. That override survives a `Unit` or `State` swap (checked on the sample host).

## Usage

- digits at `Headings/Title 1` and a `_Unit suffix` instance with **Expose nested instance** on and its text style set to the digits'.
- A host lays the suffix next to the digits with baseline alignment, gap 0: the suffix draws its own gap.
- Hosts pin `State` from their own `State`; designers pick only `Unit`.
