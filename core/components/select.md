# Select

> Core's Select, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

Text field's tree (structure.md, reading (a)), with the Field's contents changed.

```
Select (variant root)              Fill × Hug, no fill, no padding; min size Interactive/<Size> (call 4)
└─ Container                       VERTICAL, Fill × Hug, gap 8 (raw, as Text field)
   ├─ Label                        HORIZONTAL, Fill × Hug
   │  ├─ Title                     TEXT, Fill (hidden on Skeleton)
   │  └─ Skeleton title            120 × 16, radius 4 (Skeleton only)
   ├─ Field                        HORIZONTAL, Fill × Hug, min height Select/Field/<Size>/Layout min-height, centred,
   │  │                            padding 16 / 0, gap 16, radius 8, stroke 3 (Read-only 2), no clip
   │  ├─ Text overflow             Fill × Hug, padding 0 (hidden on Skeleton)
   │  │  ├─ Value text             TEXT, Fill, one line, ENDING
   │  │  └─ Placeholder text       TEXT, Fill, one line, ENDING (only with call 1 option b)
   │  ├─ Status                    Incomplete · Complete glyph, or `_Loading`
   │  └─ Chevron                   Icons instance, `chevron-down` (`chevron-up` on Active); hidden on Read-only and Skeleton
   └─ Detail                       HORIZONTAL, gap 4 (raw), hidden on Skeleton
      └─ Helper Text | Error message | Success message, with its glyph on Error / Success
```

- No `Input Cursor` and no `_Unit suffix`: nothing is typed (call 2).
- The Chevron is a plain Icons instance like Password field's eye: no Item, no target of its own; the whole field is the target.
- The open menu is not drawn inside the set (the issue's "not nested"). Base nests one in Active; we don't.

## Icon records

`Select/Icon/<Step>/Type token = fa-sharp fa-solid/<Step>`. Beside text the step follows the value text (Icons): Large → Large (17), Medium and Small → Medium (15), as Text field. The Chevron and Status glyphs take it; the Detail glyphs are Medium at every Size (beside Subheadline). `_Loading` is Medium on Large, Small otherwise.

The Chevron swaps `chevron-down` ↔ `chevron-up` in one place. Both FA glyphs are the same advance width, so the layer needs no fixed width; the build checks it (Assumptions).

## Text styles, wrapping and truncation

| Layer | Text style (Large · Medium · Small) | Lines | Text property |
| --- | --- | --- | --- |
| `Title` | `Headings/Headline` · `Body/Callout` · `Body/Subheadline` | wraps (auto height) | none yet |
| `Value text` | `Body/Body` · `Body/Callout` · `Body/Subheadline` | one line: Fill, auto height, `ENDING`, `maxLines` 1, so it truncates in Figma too (Localisation: "a Select value") | none yet |
| `Helper Text` · `Error message` · `Success message` | `Body/Subheadline` | wraps, never truncates | none yet |

`Value text` is Fill, not Hug like Text field's `Input text`: Text field went Hug so its cursor follows the last character, and Select has no cursor. The Chevron hugs at the trailing edge, so a long value ends in "…" before it.

## Hit target and Skeleton

- **Hit target**: the Root's min width and height bind `Interactive/<Size>/Interactive min-height` (ADR 0003), Container centred, as Password field. The whole field opens the list, so there's one target and the Chevron has none. The Root is always taller than 48 (Title + Field + Detail), so the target never overflows Small's 36 Field. Text field dropped its Root target (the ADR's 2026-11-02 amendment); call 4 asks whether Select follows Text field or the ADR.
- **Skeleton**: `State=Skeleton`, as Text field and Carbon's Dropdown: the Field in `skeleton-background`, the 120 × 16 Title bar, no value, chevron or Detail.

## Accessibility

- [ ] 1. Each text / background pair passes in both modes: the contrast lint, after the spec. Value on `Field/field` and on `background-primary` over each Base surface, as Text field (which passes).
- [ ] 2. Meaningful non-text parts pass 3:1: the Chevron on both fills (`icon-primary` on `field`), the strokes, the Status and Detail glyphs. The contrast lint, after the spec.
- [x] 3. The field is identified by more than its fill: the Title above, the value or prompt inside, the Chevron, and a stroke on Focus, Active and Error (Filled fields).
- [x] 4. No state by colour alone: open turns the Chevron up and adds the stroke; Error and Success carry a glyph and a message; Incomplete / Complete a glyph; Loading a spinner; Disabled dims; Read-only drops the Chevron and keeps its outline.
- [x] 6. The value stays one line and ends in "…" before the Status glyph and the Chevron. The Title, helper and error text wrap and grow the variant (Error Small with marks: 148 → 212 → 386). Nothing sits outside its box and nothing clips.
- [x] 7. No text under 11 pt: the smallest is Subheadline.

## Usage

- The Title always shows; the prompt inside ("เลือกบัญชีธนาคาร") is not the label. Thai copy in every case (บัญชีรับเงิน / เลือกบัญชีธนาคาร).
- A tap opens Menu on iOS, Dropdown menu on Android + web; the screen places the list under the field.
- Short lists only. A long or searchable list is a Search field over a list, or a Sheet with List items and a trailing Radio (Inventory).
- A country picker is a Select case, a Pattern component (#49).
- Read-only for a chosen value the user can't change in this form; Disabled only for "can't interact".
- The Focus ring once, outside the field.
