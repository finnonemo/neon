# Amount field

> Core's Amount field, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

```
Amount field (variant root)       Fill × Hug, no fill, no padding, min width and height 48 (Components/Interactive/Medium/Interactive min-height, the `hit-target` lint) (Q5)
└─ Container                      VERTICAL, Fill × Hug, gap 8 (raw, Text field's), items Start | Center by Align
   ├─ Label block                 VERTICAL, Fill × Hug, gap 0 (shown by `Label`; hidden on Skeleton)
   │  ├─ Label                    TEXT
   │  └─ Description              TEXT (shown by `Description`) (Q6)
   ├─ Skeleton label              80 × 8, radius 0 (Skeleton only; `Amount field/Bar/Default`, the Label block rule)
   ├─ Amount                      HORIZONTAL, Fill × Hug, content centred both ways, gap 0, padding 0 / 8, radius 8, stroke 2 inside on Focus / Error, its weight bound only in those cells (Q3, Q4)
   │  ├─ Input text               TEXT (Text filled = True)
   │  ├─ Placeholder text         TEXT `0` (Text filled = False)
   │  ├─ Input Cursor             instance, Class pinned per Text style; visible on Active only
   │  ├─ _Unit suffix             instance, Expose nested instance on; State pinned Enabled | Disabled; Text style one step under the digits (a variant, no override)
   │  └─ Amount bar               Fixed (Amount field/Bar/<Text style>), Skeleton only
   ├─ Suggestion row              SLOT, HORIZONTAL, Fill × Hug, gap 8 (Spacing/spacing-03), min height 48 (Sizing/hit-target), clips, scrolls sideways (shown by `Show Suggestion row`; hidden on Skeleton)
   │  └─ Suggestion 1 … 4         Button instances (pill), the Slot's default content, Hierarchy=Secondary, Type=Default, Size=Small, iOS=False, icons off; State Disabled on Disabled
   └─ Detail                      HORIZONTAL, Fill × Hug, gap 4 (raw), hidden on Skeleton
      ├─ circle-exclamation       Icons instance (Size Medium, its Color support-error), Error only (Q4)
      └─ Helper text              TEXT (the Error message on Error)
```

- The digits and suffix sit in one frame so the Focus ring and the Error stroke draw around the amount only, as the map says, and Align moves them together.
- The suffix's Unit sits beside the digits, centred on them (`Amount` centres both ways, (the owner, 2026-11-06: "ค่า auto layout ที่ฉันแก้ไป ถือว่าเป็นค่าที่ถูกต้อง ให้ไปแก้ฝั่ง doc ของคุณแทน")), with gap 0: it draws its own U+00A0 ([unit-suffix.md](unit-suffix.md)).
- The Label block follows structure.md's Label block rule with role `title`: frame `Label block`, title `Label`, description `Description`, bar `Skeleton label`. The spec declares it as `labelBlock` (Q6).
- `Suggestion row` is a Slot: its default chips carry no property links, and `isExposedInstance` can't be set on them (Slot rules, figma-scripting.md).
- No Clear, no Status glyph, no `_Loading`: the map drops Clear, and a hero amount has no Loading case.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Text style` | Display 1 · Large Title · Title 1 | the digits' style, the suffix one step under (Large Title · Title 1 · Title 2), the Input Cursor class, the Skeleton bar (Q1, Q2) |
| `Text filled` | False · True | Input text or Placeholder text |
| `State` | Enabled · Focus · Active · Error · Disabled · Skeleton | colours, the ring or Error stroke, the cursor, the Error glyph, Skeleton bars (Q3, Q4) |
| `Align` | Center · Start | Container's and the text layers' horizontal alignment |

`Text style` keeps Value's axis name and value names, so a read-only hero at the same step is `Value` with the same `Text style` ([value.md](value.md)). Value's Body, Subheadline and Footnote steps are not here: the map gives this set Title 1, Large Title and one Display step.

`State` has no `Success` and no `Read-only` (R1, R2): a valid amount shows no mark, and a read-only amount is a Value, or Text field's `State=Read-only` in a boxed form field (Amount entry).

Properties:
- BOOLEAN `Label` (default True), `Description` (default False), `Show Suggestion row` (default True), `Helper` (default True; linked to `Detail` on Enabled, Focus, Active and Disabled, never on Error, where `Detail` is the error message). `Show Suggestion row` is named apart from the Slot, which the pawisssh/design-system#388 SLOT name lint requires.
- TEXT `Label text` (`Amount`), `Description text` (`Minimum 1,000 ฿`), `Input text` (`10,000`), `Placeholder text` (`0`), `Helper text` (`Helper text`): English defaults (Localisation).
- SLOT `Suggestion row`.
- The nested `_Unit suffix`'s `Unit` shows on the instance panel.

3 × 2 × 6 × 2 = **72 variants**.

The `Digits` record covers `Input text` and `Placeholder text`. The suffix's `Unit` takes its style from the `_Unit suffix` `Text style` variant the host picks, one step under the digits (a `componentProperties.Text style` rule on the nested instance, [unit-suffix.md](unit-suffix.md)); the `Amount field/Unit/<Text style>` records describe it and bind nothing. The Label block and Detail bind Text field's styles directly (no `Size` axis to key them), and the Root's min width and height bind `Components/Interactive/Medium/Interactive min-height` (48; the build lint's `hit-target` rule for an interactive set with no Size axis). The Label block's `Skeleton label` takes `Amount field/Bar/Default` (80 × 8, radius 0), the Label block rule's bar.

## Icon records

`Amount field/Icon/Medium/Type token = fa-sharp fa-solid/Medium`: the Error glyph beside `Body/Subheadline` helper text, Text field's glyph and step (Icons). One glyph, never swapped, so no fixed-width icon layer.

## Text styles, wrapping and truncation

| Layer | Text style | Lines | Text property |
| --- | --- | --- | --- |
| `Label` | `Headings/Headline` (Label block role `title`; Text field's Large Title style) | wraps, never truncates | `Label text` |
| `Description` | `Body/Subheadline` | wraps, never truncates | `Description text` |
| `Input text` · `Placeholder text` | `Amount field/Digits/<Text style>`: Display 1 · Large Title · Title 1, `Strong` | one line, never truncates (a figure); Q7 says what gives way | `Input text`, `Placeholder text` |
| `_Unit suffix › … › Unit` | one step under, the suffix's `Text style` variant: Large Title · Title 1 · Title 2, Regular | one line, part of the figure | none (the `Unit` axis) |
| `Helper text` | `Body/Subheadline` | wraps, never truncates | `Helper text` |

- **Display on a component.** Display 1 is a content style; Amount field's largest step is the one exception the map allows (architecture.md's Type line and Amount entry). It holds only digits.
- **One step smaller.** Display 1's step under is Large Title, 34/48: IC's `฿` beside its 96-point digits is 34/48, so the map's rule lands on the product's own pair.
- **Input Cursor class.** `Display 1` (96 tall) for Display 1 and `Title 1` (40) for Title 1. The set has no `Large Title` class, so Large Title pins `Display 3` (48 tall, Large Title's line height). that's the cursor's own limit, listed under Open.
- **Tabular figures (pawisssh/design-system#122).** The digit layers set `tnum`, ready for the font, as Value does. Finnomena Trek 1.002 has no `tnum`, so digits shift width while typing until pawisssh/design-system#122 ships it. That font fix is the owner's. Carbon's Number input sets its value in IBM Plex Mono and Base has a Mono Display for the same reason. The handoff tells developers `font-variant-numeric: tabular-nums` / `.monospacedDigit` (Numbers and dates).
- Digits follow the map's entry rules: live comma grouping, whole baht allowed, decimals capped by the unit, no `.00` padding on blur. The Figma default `10,000` follows IC.

## Hit target and Skeleton

- **Hit target**: the Root's min width and height bind `Components/Interactive/Medium/Interactive min-height` (48), Container centred, per pawisssh/design-system#156 (a tap anywhere focuses the field). It matters at Title 1, whose line height is 40. This departs from Text field and Value, whose Root targets the owner removed on 2026-11-02 (Q5). Each chip in `Suggestion row` is a nested control and brings its own target (Q8).
- **Skeleton**: `State=Skeleton`: an 80 × 8 `Skeleton label` for the Label block (the Label block rule's bar), an `Amount bar` in place of the amount (`Amount field/Bar/<Text style>`), and no suffix, cursor, chips or Detail.

## Usage

The page's `Usage` frame shows:

- IC's order screen at 375: `Text style=Display 1`, `Align=Center`, Label `จำนวนเงินที่ต้องการซื้อ`, Description `ขั้นต่ำ 1,000 บาท`, `10,000 ฿`, chips `+1,000` `+10,000` `+50,000` `+100,000`.
- A sell order: set-value chips `25%` `50%` `ทั้งหมด`, each putting its share in the field (Buttons show no Selected; a row that must show one puts Selection tags in the Slot); `ทั้งหมด` switches the instance's `Unit` to Units and shows the number, never `ทั้งหมด (… หน่วย)`.
- The Focus ring once, around the amount (`State=Focus`).
- `Align=Start` at Large Title in a sheet, under a Segmented control (`บาท` · `หน่วย`) where the user must choose the unit.
- Error: `ขั้นต่ำ 1,000 บาท` as the Error message, digits still `text-primary`.
- Required: a required amount among optional fields says so in the Label, spelled out (`(required)`, Thai `(จำเป็น)`), never in the Description or the Helper. An order screen's only field carries no marker. No asterisk.
- Placeholder: `0` and only `0`, shown whenever the field is empty, Focus and Active too. The minimum is the Description, the unit is `_Unit suffix`; never an instruction in the placeholder.
- Don't: a boxed amount in a form row (use Text field with `Unit`); a fixed amount on a review screen (use Value at the same `Text style`); a sparkle or Suggested look (dropped by the map).
