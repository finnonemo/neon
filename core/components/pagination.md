# Pagination

> Core's Pagination, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

Three sets. A page item is a private Item in a Slot, as Segmented control's; Previous and Next, the selects, the search and the buttons are public Core sets nested as instances.

```
Pagination (variant root)       Fill × Hug, min height Interactive/<Size>; Type=Numbered hugs its width, Overflow fills
└─ Container                    HORIZONTAL, Fill × Hug; Numbered: centred, Overflow: space-between; wraps at large text
   ├─ [Numbered]
   │  ├─ Previous               Icon button Tertiary · Default · <Size> · iOS=False, chevron-left; hidden on page 1 by a BOOLEAN
   │  ├─ Pages                  SLOT `Pages`, HORIZONTAL, Hug; default `_Pagination item` ×7: 1 2 3 4 5 … 30 (1 Selected)
   │  └─ Next                   Icon button, chevron-right
   └─ [Overflow]
      ├─ Rows per page          HORIZONTAL, gap 8: Text `Rows per page:` + Select (no Title, no Detail, `Size`), value 10
      ├─ Range                  TEXT `1–10 จาก 100 รายการ` (Fill, wraps), `text-secondary`
      ├─ Page                   HORIZONTAL, gap 8: Select (the page number) + Text `จาก 10 หน้า`
      └─ Nav                    Previous and Next: Button Tertiary · Default · <Size> text buttons (Uber's `Prev` `Next`), Disabled at the ends
Divider ×3                      Divider instance, vertical, between the Overflow groups (Carbon's), BOOLEAN `Dividers`

_Pagination item (variant root) Hug × Hug, min size Interactive/<Size> (48 × 48), Container centred
└─ Container                    Fixed 36 × 36 (Control step), radius 8, fill by `Selected`
   └─ Label                     TEXT (Page) · `ellipsis` Icon (Ellipsis), one line

Table toolbar (variant root)    Fill × Hug, min height by Size
└─ Container                    HORIZONTAL, Fill × Hug, gap 0, `Layer/layer-01`, a `Border/border-subtle` bottom line
   ├─ [Default]  Search         Search field Size Small, BOOLEAN `Show Search`; a collapsed search is an Icon button
   │             Actions        SLOT `Actions` of Icon button Tertiary · Default · Small (Carbon's three)
   │             Primary        Button Secondary · Default · Small, BOOLEAN `Show Primary action`
   └─ [Batch actions]  Count    TEXT `เลือกแล้ว 1 รายการ`, `Text/text-inverse`, Fill, on `Background/background-inverse`
                       Actions  SLOT `Actions` of Button Tertiary · Inverse · Small
                       Divider  Divider, Cancel Button Tertiary · Inverse
```

Page items are a Slot because the pages shown change with the total (Uber has eight `Layout` values, 2–9 and 10+) and the component's values don't depend on it (Slot or axis). The Slot's `…` item opens a Menu with the hidden pages; the Menu is placed by the screen, not nested ([Select](select.md)).

## Axes

**`Pagination`**

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Type` | Numbered · Overflow | which Container parts show |
| `Size` | Medium · Small | bar min height 56 · 48, text style, Select's `Size` (P3) |
| `State` | Default · Skeleton | Skeleton replaces the parts with bars (P4) |

Properties: BOOLEANs `Show Previous` (Numbered, on), `Dividers` (Overflow, on); the exposed nested Select values and Button states. 2 × 2 × 2 = **8 variants**.

**`_Pagination item`**

| Axis | Values | Drives |
| --- | --- | --- |
| `Kind` | Page · Ellipsis | a number, or the `ellipsis` glyph that opens the Menu |
| `Selected` | False · True | Container fill, text weight; Ellipsis has no selected case |
| `State` | Enabled · Hover · Pressed · Focus · Disabled | fill, Focus ring |
| `Size` | Medium · Small | label text style |

Page 2 × 5 + Ellipsis 5 = 15, × 2 Sizes = **30 variants**.

**`Table toolbar`**

| Axis | Values | Drives |
| --- | --- | --- |
| `Type` | Default · Batch actions | the search, actions and primary button, or the count, actions and Cancel on the inverse fill |
| `Size` | Medium · Small | bar min height 56 · 48 |
| `State` | Default · Skeleton | bars in place of the parts |

2 × 2 × 2 = **8 variants**. Computed counts; Figma's are read at the build.

## Icon records

`Pagination item/Icon/<Step>/Type token = fa-sharp fa-solid/<Step>`, `ellipsis` beside the label's step. Previous and Next are Icon buttons that bring their own glyph step (`chevron-left`, `chevron-right`); Select brings its `chevron-down`. Every icon is Font Awesome; no `VECTOR` in any variant or Item.

## Hit target and Skeleton

- **Hit target**: `Pagination` is a bar of controls, so its own Root has none (the nested controls bring theirs); the Root's min height is the bar's. `_Pagination item`: `Interactive/<Size>` on the Root, 48 × 48, the 36 × 36 Container centred (ADR 0003). Uber draws it the same way: a 48 target around a 36 circle.
- **Skeleton**: `State=Skeleton` on `Pagination` and `Table toolbar`, the same on both Types: a `Skeleton/skeleton-background` bar per part (Variant axes). The items inside the Slot take their own at the build. Table cell and Table row Skeleton: P4.

## Usage

- Under a list or Table that has more rows than one screen shows. Not for a short list that loads more on scroll.
- Numbered under a list or a gallery whose pages the reader jumps between (up to about ten pages); Overflow under a Table with a total and a rows-per-page choice. Many pages and no choice of rows: Overflow without Rows per page (hide the group), not Numbered with a long Slot.
- Previous is hidden on page 1 in Numbered; in Overflow Previous and Next are Disabled at the ends (Uber's `Substate` First · Last).
- At 375 Numbered shows five items (1 2 3 … 10); Overflow wraps its groups.
- Thai copy; a Table (Medium, Selection on, one row Selected) with `Table toolbar` Default above, the `Table toolbar` Batch actions case, and Overflow as the footer; Numbered at 375; the Focus ring once.
