# Line chart

> Core's Line chart, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

```
Line chart (variant root)          Fill × Hug, no fill, no padding
└─ Container                       VERTICAL, gap Container/<Size>/Gap vertical, Fill × Hug
   ├─ Readout                      HORIZONTAL, Fill × Fixed (Content/<Size>/Readout height), shown when State=Scrubbing, the row stays so nothing shifts
   │  ├─ Date                      one line, $footnote, Text/text-secondary
   │  └─ Value                     one line, $headline Strong, Text/text-primary
   ├─ Plot                         FRAME, Fill × Fixed 160 · 96 (Content/<Size>/Plot height), clip content
   │  ├─ Gridlines                 3 hairlines (top, middle, base): chart-gridline, the base chart-axis
   │  ├─ Series                    SLOT, Fill × Fill; each child a `_Line series`
   │  ├─ _Scrubber                 ABSOLUTE; a rule 1 × the plot's height (chart-axis) and a dot (Item/<Size>/Dot size) with a 2 ring in layer-01, filled by Style; shown when State=Scrubbing
   │  └─ Empty text                centred, $subhead, Text/text-secondary; shown when State=Empty
   ├─ X axis                       HORIZONTAL, space between, Fill × Hug: three labels, $caption1, Text/text-secondary
   └─ Period                       SLOT, Fill × Hug; a Segmented control instance, Size=Small, nine items; shown when Period=Below

_Line series                       Fill × Fill, clip: `Area` (vector, fill chart-<style>-area) under `Line` (vector, stroke 3 · 2, round joins, chart-<style>); `Style` axis, one illustrative path each
```

- The readout follows the rule and is clamped to the plot's edges, like a Tooltip. In Figma it sits at the scrubber's x in a sample; in code it moves with the finger.
- **The line is a vector, so Figma draws one illustrative path per `Style` and a sample replaces it** (Q1). The Positive path rises, the Negative falls and the Neutral stays flat, so the default instance reads true. A sample puts its own `_Line series` in the Slot, with a path drawn from real data by script and the same token bound to its stroke and area; code draws the line from data and never reads these paths.
- The drag indicator is a part of the plot, not a separate set: it has no state of its own other than shown and hidden, so it is `State=Scrubbing` on the chart rather than an axis of a part.
- Gridlines are solid hairlines (Carbon's), not Investment Call's dashes: a dash pattern is not a bindable variable and a gridline carries no meaning.
- No Y-axis labels (Q9): the readout carries the value the finger is on, and the X axis names the span.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Style` | Positive · Negative · Neutral | the line, the area and the dot: `chart-positive` · `chart-negative` · `chart-neutral` and their `-area` twins. Positive when the period ends higher than it began, Negative lower, Neutral when level or unknown |
| `State` | Data · Scrubbing · Empty · Skeleton | Data: the line. Scrubbing: the line with the drag indicator and the readout. Empty: the gridlines and the `Empty text`, no line. Skeleton: the plot in `skeleton-background`, no gridlines or axis labels |
| `Period` | Below · None | whether the period selector shows under the X axis (Q2). None where the host picks the span elsewhere |
| `Size` | Medium · Small | the plot's height, 160 · 96. Medium is Investment Call's chart; Small fits a card |

Properties: `Series` (SLOT), `Period` (SLOT), `Empty text` (TEXT, English default), `Readout date` and `Readout value` (TEXT), `X label 1`, `X label 2`, `X label 3` (TEXT). 3 × 4 × 2 × 2 = **48 variants** on the chart, 3 on `_Line series`. `State=Scrubbing` with `Style` or `Size` does not multiply: each combination is a real case. `Style` is not a state of the data: the host sets it from the sign of the period's change, and it can change when the period does.

## Scrubbing

- **Start**: a horizontal pan on the Plot, or a press and hold (about 0.2 s). A vertical pan scrolls the page, so the Plot never traps a scroll. The pointer on the web starts it on hover and holds it while a button is down.
- **While**: the rule and dot sit on the nearest data point and move with the finger; the readout shows that point's date and value. The Plot is the whole interactive area, at least 96 high and Fill wide, so the 48 Hit target (ADR 0003) is met by the size, with no extra padding.
- **End**: the rule, dot and readout leave when the finger lifts; there is no pinned point (Apple's behaviour).
- **Keyboard and assistive tech**: see Accessibility, item 9. A host that does not want a gesture leaves it unwired and shows `State=Data`.

## Component variables and Theme tokens

`Components`, Tag's three-level shape, in the Extension's local collection ([allocation-bar.md](allocation-bar.md) Q2). The closed group list is Core's, so `Plot` is `Content` and the drag indicator `Item` here, as the allocation bar did for its segment and legend.

| Group | Keyed by | Properties | Values (Medium · Small) |
| --- | --- | --- | --- |
| `Line chart/Container` | `Size` | Gap vertical | `spacing-04` (12) · `spacing-03` (8) |
| `Line chart/Content` | `Size` | Plot height, Readout height | `spacing-13` (160) · `spacing-12` (96); `spacing-08` (40) · `spacing-07` (32) |
| `Line chart/Item` | `Size` | Dot size | `spacing-04` (12) · `spacing-03` (8) |
| `Line chart/Label` | role: `Readout date`, `Readout value`, `Axis` | Type token, Type emphasis, Align horizontal, Align vertical, Decoration | `$footnote` Regular · `$headline` Strong · `$caption1` Regular; `Left`, `Top`, `-` |

Templates: `Components/Line chart/<Group>/{{Size=*}}/<Property>`. Every value aliases a Scale step. **Literals, logged as in the allocation bar**: the line width (3 Medium · 2 Small), the rule width (1) and the dot's ring (2) are stroke weights, which have no Scale.

`Theme`: no Component-scoped token. Every colour is a Core `Chart/*` token (charts.md), so the file has no colour collection:

| `Chart/chart-negative` | Red/125 | Red/115 | **5.39** Light, **4.02** Dark |
| `Chart/chart-neutral` | Navy/55 | Grey/50 | **4.09** Light, **4.41** Dark |

| `Chart/chart-gridline`, `Chart/chart-axis` | Navy/12A · Navy/25A | White/15A · White/25A | decorative: the labels and the readout carry every value; the rule is a guide, the dot locates the point |

The three line colours are checked at 100% alpha on `layer-01`; the area is a tint below them and is never read against a surface.

## Icon records

None: the chart draws no Icon. The gain and loss mark that backs the colour (a sign, an arrow) belongs to the host's header value (Q5).

## Text styles, wrapping and truncation

| Layer | Text style | Lines | Text property |
| --- | --- | --- | --- |
| `Readout date` | `$footnote` (13) | one line | `Readout date` |
| `Readout value` | `$headline` Strong | one line, never cut | `Readout value` |
| X axis labels | `$caption1` (12, the Thai floor for one line) | one line each | `X label 1` … `3` |
| `Empty text` | `$subhead` (15) | up to two lines, centred | `Empty text` |

A label never wraps or truncates: the three X labels are short (a month, a day and month, a time), and the host picks them to fit. The readout clamps inside the plot, so it never leaves the screen.

## Hit target and Skeleton

- **Hit target**: the Plot is the touch area, Fill × at least 96, over the 48 (ADR 0003). The period selector keeps Segmented control's own: the Root's 48 minimum height, with segments as wide as their share of 343 (37.2, under 48 and over WCAG 2.5.8's 24, touching), the same trade [segmented-control.md](segmented-control.md) settled for the period selector (call 9).
- **Skeleton**: `State=Skeleton` fills the plot with `skeleton-background`, no gridlines, no labels, no readout; the same height as Data so nothing shifts on load. The selector stays live.

## Motion

| Transition | Token | Reduced form | Haptic |
| --- | --- | --- | --- |
| The line draws in from the leading edge when data arrives | `moderate-02 · entrance` (a clip from the left) | instant | None |
| A new period replaces the line | `fast-02 · standard` crossfade | instant | None (the selector's own `Selection`) |
| `Style` flips with the period (green to red) | `fast-02 · standard` colour crossfade | kept (colour only) | None |
| The drag indicator appears and leaves | `fast-01 · standard` (opacity) | instant | `Selection` once, when scrubbing starts (Q4) |
| The rule, dot and readout follow the finger | none: they track it | kept | None per point |
| Skeleton to Data | `fast-02 · standard` crossfade | instant | None |

The draw-in is an app behaviour, not a Figma variant. Haptics are the architecture's names (Motion and haptics): never per point (a year of days is 365 buzzes, and `Impact` is for a snap, not a drag), never alone (the rule and dot appear with it), and following the system's haptics setting. A value that crosses the period's first or last point does not add a second haptic.

## Accessibility

- [x] 1. Each text / background pair passes in both modes: the readout, the labels and the empty text are `text-primary` or `text-secondary` on the host surface.
- [x] 2. Each meaningful non-text part passes 3:1 against `layer-01`: the line and the dot, in both modes (3.85 / 7.50, 5.39 / 4.02, 4.09 / 4.41). Gridlines, the axis rule and the areas are decorative; every value they stand beside is also a label or the readout.
- [ ] 3. N/A: not a field.
- [x] 4. **No meaning by colour alone**: the green and red mean gain and loss only beside text. The chart's accessible name states the change in words and a sign, and the host's header value carries the sign, an arrow and the percentage (Q5). A chart in `Neutral` is not "no change" by colour; the name says so.

- [ ] 6. the readout and axis labels grow in height and the plot keeps its height;
- [x] 7. No text under 11 pt: the smallest label is 12.
- [x] 8. Motion table above.
- [ ] 9. Role, accessible name, announced states:

## Usage

- Both modes, Light and its Dark twin, with Thai copy (Localisation). The Focus ring on one sample was planned; **reversed by the build**: Segmented control's `State` is Enabled · Disabled · Skeleton and has no Focus value, so no sample shows a ring beyond the selected item's own outline.
- **Investment Call's case** (`Subscription Chart`): the Positive and Negative charts with the nine-label selector under them, the 1Y or 3M label selected, and the X axis in Thai months (`ก.ค.`, `พ.ย.`, `มี.ค.`; a day chart `09.30 น.`, `12.30 น.`, `16.30 น.`).
- **Dragging**: Positive and Negative in `State=Scrubbing`, the readout `30 ก.ย. 69` and `12.40 ฿`, the rule and dot at about two thirds of the plot.
- **Empty and Skeleton**: `ไม่มีข้อมูลในช่วงนี้` over the gridlines, then the skeleton plot.
- **A compact card**: `Size=Small`, `Period=None`, Neutral, beside a host header.
- Use it for one series over time with a span the reader can change. Don't use it for a split of a whole ([Allocation bar](allocation-bar.md)), one progress amount ([Progress bar](progress-bar.md)) or a list-row trend (the later sparkline).
