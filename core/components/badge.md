# Badge

> Core's Badge, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

```
Badge (variant root)            Hug × Hug, no fill, stroke or padding
└─ Container                    HORIZONTAL, Hug × Hug, centred; fill, min size, padding, radius bound
   └─ Label                     TEXT, WIDTH_AND_HEIGHT, one line; hidden in Dot
```

No Items, Slots or nested instances.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Content` | Count · Dot | Container's min size and padding, Label's visibility and colour |

Properties: `Number` (TEXT on `Label`, default `1`). 2 = **2 variants**.

The ticket's `Type` axis is named `Content` (see Calls).

## Text styles, wrapping and truncation

| Layer | Text style | Lines | Text property |
| --- | --- | --- | --- |
| `Label` | `Utility/Caption 1` (12 / 18), Type emphasis Regular | one line, never truncated: a figure | `Number` |

- Digits only: no Thai, no thousands separator, no unit. `99+` is the widest content. A count of 0 hides the Badge; above 99 shows `99+`. Figma can't enforce these, so they go to developers in the handoff.
- Caption 1's 18 line height fits inside the 20 min-height, so nothing clips at `Large`.
- The coupling: a change to Footnote's line height in (v3) Foundations / Typography moves the Badge.

## Usage

The page's `Usage` frame, in Light and Dark:

- a Count on a tab icon, with a Thai tab label (`แจ้งเตือน`);
- a Dot on a bell Icon button;
- a Count at the trailing end of a row (`ข้อความ`, `12`);
- `99+`;
- "Not a Badge": a word such as `ใหม่` / "New" is a Display tag.

No `iOS` looks and no Focus ring to show.
