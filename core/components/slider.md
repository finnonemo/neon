# Slider

> Core's Slider, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

```
Slider (variant root)          Fill × Hug, no fill, no padding
└─ Container                   VERTICAL, gap 8, padding and radius Container/<Type>/*, fill: Inset transparent · Full-bleed Layer/layer-01, Fill × Hug
   ├─ Header                   HORIZONTAL, gap 8, padding 16 each side (Header/Medium/*), Fill × Hug; shown by the Header boolean (on)
   │  ├─ Title                 TEXT, Fill × Hug, wraps; "Title text" = "Volume"; hidden on Skeleton
   │  ├─ Title skeleton        40 × 8 bar (Bar/Title), Skeleton/skeleton-element; Skeleton only
   │  └─ Value                 TEXT, Hug × Hug, one line; "Value text" = "50" (Single), "Range value text" = "20–80" (Range)
   ├─ Rail                     HORIZONTAL, gap Rail/<iOS>/Gap horizontal, padding 16 each side (Rail/<iOS>/Padding), Fill × Hug, items centred; min height Interactive/Medium (48), the Hit target layer
   │  ├─ Lower input           Range only: as Input, "Lower input text" = "20"; shown by Number input (off)
   │  ├─ Min icon              Ends=Icon: Icons instance, Size Medium, fixed 24 wide, glyph centred, Icon Text "volume-low"; shown by Min (off)
   │  ├─ Min text              Ends=Text: TEXT "0" (Min text), Subheadline text-secondary, fixed width; shown by Min (off)
   │  ├─ Min block             Skeleton: 16 × 8 bar (Bar/End), skeleton-element; shown by Min (off)
   │  ├─ Track                 HORIZONTAL (for its ABSOLUTE children), Fill × Fixed Track/<iOS>/Layout height, Round, no clip; skeleton-element on Skeleton
   │  │  ├─ Ticks              ABSOLUTE, 2 wider than the Track each side (half a Tick) and 4 below it, constraints Stretch × Bottom (iOS kit); HORIZONTAL, SPACE_BETWEEN; shown by the Ticks boolean (off)
   │  │  │  └─ Tick 1–5        Fixed Tick/<iOS>/Layout width × height, Round
   │  │  ├─ Indicator          Single, not Skeleton: ABSOLUTE, x 0, constraints SCALE × Top, width a share of the Track (0.5), Fixed height, Round, no layout, no clip
   │  │  │  └─ Thumb anchor    2 × 24, straddling the Indicator's trailing edge, constraints Right × Center; HORIZONTAL, centred both ways, no clip
   │  │  │     ├─ Value pin    ABSOLUTE, a 2-wide column centred on the Thumb, 8 above it: Head (Hug × 40, padding 8 · 12, round, background-inverse; Text Subheadline text-inverse, "Pin text" = "50") over a 4 × 8 Needle; shown by Value pin (off), Single · iOS=False · Pressed only
   │  │  │     └─ Thumb        in the anchor's flow, so centred on the edge whatever its width; Fixed Thumb/<iOS>/Layout width × height, Round; the kit's two shadows
   │  │  └─ Range indicator    Range, not Skeleton: ABSOLUTE across the Track (Stretch × Top), no auto layout
   │  │     ├─ Lower           the empty start, share 0.2, constraint SCALE
   │  │     └─ Fill            share 0.6 from Lower's end, constraint SCALE, the Indicator's height, radius and colours
   │  │        └─ Upper anchor at the Fill's trailing edge; its Thumb takes Pressed
   │  ├─ Max icon · Max text · Max block   as Min, "volume-high" · "100" (Max text); shown by Max (off)
   │  └─ Input                 Hug × Hug, min 48 × 48 (Interactive/Medium), text centred, padding 0 · 12, radius 8, Field/field (Disabled field-disabled); Text Body text-primary, "Input text" = "50" (Range: "Upper input text" = "80"); shown by Number input (off)
   └─ Divider                  Full-bleed only: Core's Divider Inset=None, ABSOLUTE at the Container's bottom, 16 in each side; shown by Bottom border (on)
```

- No `_` Items and no Slots. The two icons are Icons instances, as Progress bar's glyphs; the Divider is Core's Divider.
- The Indicator's width is the share of the Track the value fills, Progress bar's `share` rule. The Thumb rides at the Indicator's trailing edge inside a 2-wide anchor, as Carbon's `Circle overflow` and the kit's 2-wide Knob do, so no rule positions it: a designer drags the Indicator's width and the Thumb follows. The default share is 0.5; `Value` is not an axis (see Axes).
- Range's `Lower` and `Fill` sit on SCALE constraints in a frame with no auto layout, so they keep 0.2 and 0.6 of the Track when Number input or the end texts narrow it; a designer moves and resizes the Fill, and both Thumbs follow its edges (Build log, Range fill).
- Pinned to the leading edge, so it mirrors in RTL in code.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Layout` | Single · Range | one Thumb on the Indicator, or Range's Fill with a Thumb at each end (R1) |
| `Type` | Inset · Full-bleed | the bare control, or the filled row for a list: Container `layer-01`, padding 12 · 0, square corners (the list's group owns the radius), a bottom Divider (R6) |
| `Ends` | Icon · Text | what `Min` and `Max` show: the Icons glyphs or the figures "0" and "100" (R3) |
| `State` | Enabled · Pressed · Disabled · Skeleton | colours; Skeleton is bars and the Track in `skeleton-element` (R4) |

Focus is not a `State` value: the Focus ring is shown once in Usage (Visuals).

Properties: `Header` (BOOLEAN, on), `Title text`, `Value text` (Single), `Range value text` (Range), `Min`, `Max` (BOOLEAN, off; each shows the icon, the text or the Skeleton block; the glyph is the nested Icons instance's `Icon Text`, typed per use, so no INSTANCE_SWAP), `Min text`, `Max text` (Ends=Text), `Ticks` (BOOLEAN, off), `Number input` (BOOLEAN, off), `Input text` (Single), `Lower input text`, `Upper input text` (Range), `Value pin` (BOOLEAN, off), `Pin text`, `Bottom border` (BOOLEAN, on, Full-bleed). A TEXT property has one default set-wide, so Range's figures have their own properties. 2 × 2 × 2 × 4 × 2 = **64 variants**; grid rows `Layout` × `State`, columns `Type` × `Ends` × `iOS` (False, True), 8 × 8.

The value isn't an axis: the kit's five `Value` variants differ only in the fill's width, which is a drag here.

## Icon records

`Slider/Icon/Medium/Type token = fa-sharp fa-solid/Medium`, for the Min and Max glyphs (`volume-low` and `volume-high` by default, typed into the instance's `Icon Text` per use). The Icons instance is fixed 24 wide with the glyph centred, so swapping a glyph doesn't move the Track (Icons, ADR 0006).

## Text styles, wrapping and truncation

| Layer | Text style | Lines | Text property |
| --- | --- | --- | --- |
| `Title` | `Headings/Headline` (17/24, Medium) | wraps; never truncated | `Title text` |
| `Value` | `Body/Subheadline` (15/24, Regular) | one line, Hug; a figure never truncates | `Value text` |

- The Title names the control, Toggle's Title role, not a Label block: the Header is a title and a figure in a row, so the spec declares no `labelBlock`.
- The Value is one text property: the designer types it to match the share they drag ("50", "฿12,000", "3 จาก 5").
- Thai floors met: 15 is the smallest.

## Hit target and Skeleton

- **Hit target**: `Interactive/Medium` (48) as the Rail's min height (`hitTargetLayer` Rail), the layer the user drags, with the Header above it outside the target (ADR 0003). Both looks: the kit's 50 row snaps to 48 and its 24 knob sits centred in it. the inputs take the same 48 min height.
- **Skeleton**: `State=Skeleton` (R4), Carbon's skeleton item in Toggle's tokens: a 40 × 8 bar for the Title, 16 × 8 blocks for Min and Max (shown by those booleans), the Track and the Value in `skeleton-element`; no Thumb, Ticks, pin or input. Drawn in every `Layout`, `Type`, `Ends` and `iOS`.

## Motion

| Transition | Token | Reduced form | Haptic |
| --- | --- | --- | --- |
| The Thumb follows the finger; the Indicator grows with it | none: it tracks the drag | kept: it is the user's own movement | `Impact` on each step crossed, where the slider has steps (Q2); a continuous slider fires `Impact` at its minimum and maximum only |
| Pressed: `iOS=False` colours change | `fast-01 · standard` | kept (colour only) | None |
| A tap on the Track: the Thumb jumps to the value | `moderate-01 · standard` | instant | `Impact` on arrival |

This adds `Impact` to Motion and haptics, amended in this PR: an `Impact` row in its haptics table, a Slider row in its per-component table, and its "No Impact in Core" lines. Where iOS draws the slider (Q7), the system's motion and haptics stand instead.

|  | Web |
| --- | --- |

## Usage

The `Usage` frame shows, with Thai copy, both looks:

- A setting with a title and a value ("ระดับเสียง", "50").
- Range ("ช่วงราคา", 20–80).
- Number input: Single ("จำนวนเงินลงทุน") and Range with two inputs ("ช่วงอายุ").
- With Min and Max icons, Header off, as in a media control.
- Text ends (`Ends=Text`, 0 · 100, "ความสว่าง").
- With ticks, stepped ("ความเสี่ยงที่รับได้", 1–5).
- Pressed and Disabled.
- The value pin, Header off, `iOS=False` Pressed.
- The Focus ring once, on `iOS=False`.
- Skeleton, Single and Range.
- A Full-bleed list of three rows (ความสว่าง, ระดับเสียง, ขนาดตัวอักษร), the last with Bottom border off, both looks.
- Number input with Range: turn Min and Max off, since the inputs show the ends;
- Don'ts: not for an exact figure (Amount field); not for 2–5 named options (Segmented control); not for a count changed one at a time (Stepper); not to show progress (Progress bar).
