# Link

> Core's Link, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

PR 1 added the Container's fill; PR 2 the Root's min size and each Size's Container records.

```
Link (variant root)             Hug × Hug, VERTICAL, centred, no fill, no padding; min width and height
│                               Interactive/Medium/Interactive min-height (48) at every Size (Q9)
└─ Container                    HORIZONTAL, Hug × Fixed (Link/Container/<Size>/Layout height: 36 · 32 · 28),
   │                            padding 2 · 6 / 4 / 4, gap 8, radius 8
   │                            fill: Transparent; Layer/layer-hover-01 on Primary Hover, Layer/layer-active-01 on Active (new)
   │                            stroke: Focus/focus on Focus, Focus border-width
   ├─ Link                      TEXT, Hug; `Label` property (new); never underlined on the main (Cmd+U on the instance)
   └─ Trailing Icon             TEXT `arrow-right`, fa-sharp fa-solid/<Size>; `Trailing icon` property (new)
```

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Style` | Highlight · Primary | Ink: `Link/*` on Highlight, `Text/text-primary` on Primary |
| `State` | Enabled · Hover · Focus · Active · Visited · Disabled | Ink and Container fill; Focus ring. Was `States` until PR 2 (Q8) |
| `Size` | Large · Medium · Small | Text style (Body · Subheadline · Footnote) and icon step |

Properties (new): `Label` TEXT, default `Link`, on `Link`; `Trailing icon` BOOLEAN, default true, on `Trailing Icon`.

2 × 6 × 3 = **36 variants**, as before.

No `Underline` axis (Q3 revised, owner 2026-11-05: "Instance override, no axis"). Every variant's `Link` layer is linked to the one `Label` TEXT property, and Figma copies a text style or decoration set on one linked layer to all of them, in its UI as through the plugin API (Build log). An override on an instance stays on that instance, so the underline is Cmd+U on the instance; 21 instances on 🚧 Drafts already do this.

## Icon records

`Link/Icon/<Size>/Style = fa-solid`, `Size = large · medium · small`; the icon follows the label's step. Glyph `arrow-right` in every variant; one glyph, so no fixed-width layer. Unchanged.

## Hit target and Skeleton

- **Hit target**: since PR 2 the Root's min width and height bind `Interactive/Medium/Interactive min-height` (48) at every Size (Q9), as ADR 0003 asks, with the Container centred: Large 64 × 48, Medium 58 × 48, Small 52 × 48 with the default label and icon. A parent that nests Link sets no min size of its own (`_Breadcrumb item` dropped its). An inline text link is exempt (Layering and structure).
- **Skeleton**: None: a Link is shown with its label, or the label's own block skeletons it.

## Usage

- Primary for a standalone action in neutral text (List item's trailing Link, Section heading); Highlight for a link that must read as a link in body copy (Toggletip).
- Underline (Cmd+U on the instance's label) for an inline link in running text and for Breadcrumbs; a standalone Link stays plain (Accessibility).
- `Trailing icon` off where the link sits in a row or a path; on where it leads to another page.
