# Tabs

> Core's Tabs, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

```
Tabs (variant root)             Fill × Hug, no fill, no padding
└─ Container                    HORIZONTAL, Fill × Hug, gap 0, padding 0;
   │                            clips content in every variant (set in the base: the engine keys no clip);
   │                            only Intrinsic overflows, and scrolls horizontally
   ├─ Track                     absolute, constraints Stretch × Bottom, 1 tall, `border-subtle` (Pill: `Transparent`): the track;
   │                            first child, so the tabs' Line draws over it
                                Fixed: Fill × Hug, its _Tab instances Fill; Intrinsic: Hug × Hug, instances Hug.
                                Default content: three _Tab (Overview Selected, Funds, Stocks), in English

_Tab (variant root)             Fixed: Fixed × Hug (125, a third of 375; Fill as an instance in the slot) · Intrinsic: Hug × Hug;
│                               min width and height Interactive/Medium (48); no fill, no padding
└─ Container                    HORIZONTAL; Fixed: Fill × Hug, Intrinsic: Hug × Hug; fill (Active)
   ├─ Content                   HORIZONTAL, padding 12 · 16, gap 8, centred; Fixed: Fill × Hug, Intrinsic: Hug × Hug;
   │  │                         stroke 2 inside, all sides, excluded from layout: the Focus ring
   │  ├─ Icon                   TEXT, Font Awesome ligature, `fa-sharp fa-solid/Medium`; BOOLEAN `Icon`, off
   │  ├─ Label                  TEXT, one line, `Body/Subheadline`; TEXT property `Label`
   │  └─ Badge                  instance of Badge, `Content=Count`; BOOLEAN `Badge`, off
   └─ Line                      absolute, constraints Stretch × Bottom, 2 tall: the selection indicator;
                                last child, so it draws over Content's Focus ring
```

- One-line tab: 12 + 24 + 12 = 48, the Hit target. Strokes sit inside and are excluded from layout (structure.md).
- The indicator and the track are absolute fill layers, not bottom strokes: the build engine binds a stroke weight on all four sides only. `Line` is `_Tab` Container's last child, so a focused selected tab shows the ring with the indicator drawn over its bottom edge.
- `Track` is the Tabs Container's first child and the tabs come after it, so a selected tab's `Line` draws over the 1 px track. It stretches across Container, so it runs past the last tab in Intrinsic without Base's `Extension` frame.

## Axes

`_Tab`:

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Width` | Fixed · Intrinsic | Container's and Content's Layout horizontal (Fill or Hug) |
| `Selected` | False · True | the indicator (`Line`'s fill) and the Label colour |
| `State` | Enabled · Active · Focus · Disabled | Container's fill (Active), Content's stroke (Focus), Label, Icon and indicator colours (Disabled) |

Properties: `Label` (TEXT), `Icon` (BOOLEAN, off), `Badge` (BOOLEAN, off). 2 × 2 × 4 = **16 variants**; with Skeleton (`Selected=False` only), 2 × (5 + 4) = 18.

`Tabs`:

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Width` | Fixed · Intrinsic | the Tabs frame's Layout horizontal and which `_Tab` `Width` the default content uses |
| `Style` | Underline · Pill | the Track's fill (Pill: `Transparent`), the Tabs frame's gap (Pill: 8) and the default content's `Style` |
| `Size` | Medium · Small | the default content's `Size`; Pill only |

Properties: the SLOT `Tabs` on the inner frame, made by hand and listed in the spec since #357. Figma refuses to expose instances inside a Slot, so a designer selects a tab in the Slot to set its Label, Icon and Badge. Pill is Intrinsic only and Underline Medium only, as on `_Tab`: Underline Fixed, Underline Intrinsic, Pill Medium, Pill Small = **4 variants**, one a row. The slot's variables (its gap) sit under `Tabs/Container`.

`Width` sits on `_Tab` too: Slot content isn't pinned (Variant axes), so a designer sets each `_Tab`'s `Width` to match the bar's.

## Icon records

`Tabs/Icon/Medium/Type token = fa-sharp fa-solid/Medium`: beside Subheadline (15) the step is Medium, 15 / 24 (Icons, ADR 0006). One glyph per tab, the designer's; no fixed-width layer, since glyphs don't swap within a tab.

## Text styles, wrapping and truncation

| Layer | Text style | Lines | Text property |
| --- | --- | --- | --- |
| `Label` | `Body/Subheadline` (15 / 24), Type emphasis Regular | one line, never cut (a control label, Localisation) | `Label` |

- A label that doesn't fit is a copy or layout problem: Fixed is for two or three short labels; more or longer labels use Intrinsic, which scrolls (Calls).
- Thai floor: 15, over 12.

## Hit target and Skeleton

- **Hit target**: `Interactive/Medium` on the `_Tab` Root, 48 × 48 minimum (ADR 0003); Container centred. A one-line tab is 48 tall. `Tabs` itself isn't a target; its tabs are.
- **Skeleton**: recommended None (see Calls).

## Motion

| Transition | Token | Reduced form | Haptic |
| --- | --- | --- | --- |
| the indicator moves to the selected tab; label colours swap | `fast-01 · standard` | instant | None |

Segmented control differs on purpose (`moderate-01 · standard`, crossfade, `Selection`): a tab changes the section, not a value, and Core fires `Selection` only between segments (Motion and haptics). Its row is in that table (2026-11-05).

## Accessibility

- [ ] 1. Label `text-secondary` 6.73 / 7.22, `text-primary` 13.87 / 15.13, on `layer-active-01` 6.31 / 5.46 or more. Disabled is exempt.
- [ ] 2. The indicator `border-strong` is 9.44:1 or more over the track on every Base surface. The track is decorative.
- [x] 3. N/A: not a field.
- [ ] 4. Selection is shown by the indicator's shape and the label's colour, and announced as Selected; Disabled by colour and announced as dimmed.
- [ ] 5. Focus is a `State` value, a 2 px `Focus/focus` stroke inside Content, as List item and Checkbox Full-bleed (Carbon's), not a ring outside: at gap 0 a ring outside would cross the neighbouring tabs (see Calls).
- [ ] 6. Intrinsic scrolls; Fixed may not fit (see Calls).
- [ ] 7. 15 pt (Subheadline), over 11.
- [x] 8. Motion: `fast-01 · standard`, reduced instant, haptic None.
- [ ] 9. Role, name, states and focus order:

|  | Web |
| --- | --- |
| Role | `role="tablist"` / `role="tab"`, panel `role="tabpanel"` |
| Accessible name | same, `aria-controls` the panel |
| Announced states | `aria-selected`, `aria-disabled` |
| Focus order | one tab stop for the list; arrow keys move between tabs |

## Usage

The page's `Usage` frame, in Light and Dark (Theme mode on each column), with Thai copy, each case a 375 screen with an English note:

- Fixed, three tabs: `ภาพรวม` · `กองทุน` · `หุ้น`, the first selected;
- Intrinsic, six tabs that scroll at 375 (`ทั้งหมด`, `กองทุนรวม`, `หุ้นไทย`, `หุ้นต่างประเทศ`, `ทองคำ`, `คริปโต`);
- Pill Medium, asset classes in a scrolling row, and Pill Small, fund types (`ทั้งหมด` · `ตราสารหนี้` · `ผสม` · `หุ้น` · `อสังหาฯ` · `ต่างประเทศ`) (P7); the Pill row starts 16 in from the screen's edge, the component's own inset;
- a tab with a Badge (`แจ้งเตือน`, `3`) and one with an Icon (`กองทุน`): Icon and Badge are per tab, turned on by selecting the tab in the Slot (owner, "ทำให้ tab รองรับ icon badge ด้วย เปิดปิดได้": both booleans were already on `_Tab`);
- the Focus ring once, on a selected tab;
- "Not Tabs": switching a period or a filter on one view is a Segmented control (`1D` … `MAX`, `บาท` · `หน่วย`); the sample shows `บาท` · `หน่วย`.

No `iOS` looks to show.
