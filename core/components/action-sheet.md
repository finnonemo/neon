- [x] 9. Role, name, states and order:

|  |  | Android (`iOS=False`) | Web (`iOS=False`) |
| --- | --- | --- | --- |
| Role | an action sheet (`UIAlertController`, `.actionSheet` style), modal; each choice a button | `ModalBottomSheet` (Compose) holding a list of buttons | `role="dialog"`, `aria-modal="true"`; each choice a `button` |
| Accessible name | the `Title`; the `Message` read after it | the same | `aria-labelledby` the Title, `aria-describedby` the Message |
| Announced states | none of its own; a destructive choice reads its label | the same | the same |
| Focus order | Title, Message, the choices in reading order, then Cancel; a two-finger scrub (escape) and a tap outside cancel | the same; Back dismisses | focus to the first choice, else to Cancel in a destructive sheet; Tab trapped; Esc and the scrim are Cancel; the page behind doesn't scroll; focus returns to the trigger |

A sheet keeps an explicit Cancel; the scrim, Esc and swipe-down are supplemental (Uber, Sheet and Dialog). `Show Cancel` off is for a sheet that has another explicit dismiss (an iPad popover, where a tap outside is the system's cancel).

## Usage

- Page `Action Sheets` (new, between `Accordions` and `Alerts`, from the `Templates` clone): the set in Components; no Items.
- Samples in Light and Dark columns, Thai copy as instance overrides, over a screen with the `Miscellaneous/overlay` scrim:
  - A destructive choice, both looks (Mail's draft): "ทิ้งร่างนี้?", `Show message` off, "บันทึกร่าง" (Secondary), "ลบร่าง" (`Type=Danger`, Primary), Cancel "แก้ไขต่อ" (keep editing).
  - Source chooser, no destructive choice, so no Primary, `Show message` off: "เลือกแหล่งที่มา", "ถ่ายรูป" · "เลือกจากคลังภาพ" · "เลือกไฟล์" (the File upload Pattern, [file-upload.md](file-upload.md)), "ยกเลิก".
  - With a message (the title alone isn't enough): "ลบรูปภาพนี้?", Message "รูปภาพจะถูกลบออกจากอัลบั้มนี้ แต่ยังอยู่ในคลังภาพ", "ลบจากอัลบั้ม" (`Type=Danger`, Primary), "ย้ายไปอัลบั้มอื่น" (Secondary), Cancel "ยกเลิก".
- Not for: a question that needs an answer, or a confirmation with two or three actions (Alert); a form, long content or several steps (Sheet); a choice from a control on a pointer device, or one with its own state (Menu); feedback that needs no answer (Snackbar, the banners).
- Two to four choices besides Cancel, as the HIG's four buttons (watchOS) and its "avoid letting an action sheet scroll": the sheet hugs its content, and a longer list is Sheet or Menu. The title says what the choice is about and fits one line; a message only where the title isn't enough; the choices are verbs, a destructive one first, Cancel last.

### Hierarchy

Action Sheet pins its Buttons' `Hierarchy`; the shared rules are in [hierarchy.md](../hierarchy.md). A sheet is its own context, so a destructive choice that confirms the action is its one Primary (rule 1, [Destructive flow](button.md) step 2: "a confirmation dialog or sheet"); a sheet with no destructive choice has no Primary, its choices being equal related actions ([H7](../hierarchy.md)).

| Button | Pinned | Use for | Apple role |
| --- | --- | --- | --- |
| Choice (in `Actions`) | Secondary, `Type=Default` | each option: "บันทึกร่าง", "ถ่ายรูป" (rule 3) | Normal |
| Choice, destructive | Primary, `Type=Danger` (set on the instance), after the Secondary choices, as the Button dock stacks them (Uber: Secondaries, then Primary, then Cancel; the owner, 2026-11-11) | the choice that removes data and so confirms the action: "ลบร่าง"; Primary Danger is loud but not the default in code (Destructive flow step 4) | Destructive, never the default |
| `Cancel` | Tertiary, `Type=Default` | the way out (rule 4) | Cancel |
