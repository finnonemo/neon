# Allocation bar

> Core's Allocation bar, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

```
Allocation bar (variant root)    Fill × Hug, no fill, no padding
└─ Container                     VERTICAL, gap 12 (Container/<Size>/Gap vertical), Fill × Hug
   ├─ Bar                        HORIZONTAL, gap 2 (Bar/<Size>/Gap horizontal), Fill × Fixed 8 · 16 (Bar/<Size>/Layout height), radius 0, clip content, fill Chart/chart-empty (the track)
   │  └─ Segments                SLOT, Fill × Fill; each child an `_Allocation segment`, grown by its share (Q3)
   ├─ Legend (List)              SLOT, VERTICAL, Fill × Hug; List item instances, Size=Small, Leading=Small, Trailing=Value; shown when Legend=List
   └─ Legend (Inline)            HORIZONTAL wrap, gap 16 × 8, Fill × Hug; `_Legend item` instances; shown when Legend=Inline

_Allocation segment              Fill × Fill (grow = its share), min width 4, no radius, fill Chart/chart-categorical-NN or chart-other by `Series`
_Legend item                     HORIZONTAL, gap 8, Hug × Hug: `square-small` Icon, fill by `Series`; label (Body, one line, Text/text-primary)
```

- A segment and a legend swatch take the same `Series`, so the bar and its legend can never disagree on a colour (ADR 0011: one meaning, one slot).
- The track shows only where the segments don't fill the bar (`State=Empty`, or a total under 100%). A gap of 2 (`spacing-01`) shows the surface between adjacent segments, so neighbours need no contrast with each other (Accessibility).
- No header, title or caption: a title and a caption are the host's text ([Tile](tile.md) or a Pattern); Carbon's header carries chart actions, which this static bar has none of.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Legend` | List · Inline · None | which legend shows: List item rows (Port, with amounts), a wrapping mark-and-label row (Carbon, no amounts), or none (the host labels it) |
| `Size` | Medium · Small | the bar's height, 16 · 8 |
| `State` | Data · Empty · Skeleton | Data: segments. Empty: the bare track, as Port's `Value = False`. Skeleton: the track pulses, no legend |

`_Allocation segment`: `Series` = 01 · 02 · 03 · 04 · 05 · 06 · 07 · 08 · Other (9). `_Legend item`: the same `Series`.

Properties: none on the bar; the segments and legend rows are content (Slots). 3 × 2 × 3 = **18 variants** on the bar, 9 on each Item. The domain colours (`Chart/Asset allocation/equity`, …) are not an axis: a fill override bound to the domain token, the recipe List item's legend row already uses ([R1](list-item.md)), so one set serves every domain set without a `Domain` axis that grows with each new set.

## Icon records

`Allocation bar/Icon/Small/Type token = fa-sharp fa-solid/Small`, the `square-small` swatch of `_Legend item`, a fixed-width layer so a label never shifts. In the List legend the swatch is List item's own `square` Icon, as built in #170.

## Text styles, wrapping and truncation

| Layer | Text style | Lines | Text property |
| --- | --- | --- | --- |
| `_Legend item` label | `$subhead` (15/24) | one line | `Label text` |
| List legend's label and value | List item's | as List item (Label one line `ENDING`, Value one line, never cut) | List item's |

An Inline legend wraps to a new row between items, never inside one. A label that doesn't fit one row alone ends `ENDING`.

## Hit target and Skeleton

- **Hit target**: None: static. A slice that opens a detail is the List legend's row, with its Chevron, and brings List item's own 48 (ADR 0003); the bar itself takes no tap, so a hit target on it would hide nothing and mislead. Scrubbing a bar is out (Q4).
- **Skeleton**: `State=Skeleton`: the track in `skeleton-background` (as [Tile](tile.md)), no segments, no legend, the same height as Data so nothing shifts on load.

## Usage

- Both modes, Light and its Dark twin, with Thai copy (Localisation); the Focus ring does not apply.
- **Port's allocation case** (`Asset Detail Chart`): a two-part bar, the asset value (`มูลค่าสินทรัพย์`, `Series 01`) and the cash in the account (`มูลค่าเงินสดในบัญชี`, `Other`), with the List legend and the amounts `250,000.00 ฿` and `50,000.00 ฿`, then `Empty` (`0.00 ฿`) and the `-- ฿` error legend. Port's two product hues (purple, blue) are not chart colours: a Pattern may wrap the bar for one product, but the bar takes the Chart palette (Q5).
- **An asset allocation**: six parts from `Chart/Asset allocation/*` (หุ้น · ตราสารหนี้ · ทองคำ · เงินสด · พันธบัตรรัฐบาล · อื่นๆ) over the Inline legend, then the same bar over the List legend with percentages summing to 100.00.
- Use it for a whole split into 2–9 parts. Fold a ninth and later part into `Other`. Don't use it for one progress amount ([Progress bar](progress-bar.md)), a trend (line chart) or a ring (Donut).
- Segments are set by share. Re-weight by setting each segment's Fill share (Q3).

Two findings from the samples:

- **Port's empty and error cases are `State=Data` with the Segments slot emptied**, not `State=Empty`: Port keeps the two legend rows (`0.00 ฿`, `-- ฿`), and `State=Empty` hides the legend by design. `State=Empty` is the bare track alone, for a host that labels it elsewhere.
- **A row's mark colour is an override** on the `List item`'s `Icon` text (`fills`, `styledTextSegments`: `usage-overrides.js` lists 24 as `gaps`, one per row). That is Q5's call (a domain's colour is set on the row and the segment, since `Leading` has no colour property); the Inline legend's marks and the segments are Slot content and do not show as gaps. Its other output: `passDown`, `borrowed` empty; `defaults` lists only the Baht unit ` ฿` (meant) and the Component Header's namespace.

Contrast of every fill the samples bind, on `layer-01` (white Light, #1A1A1A Dark): Light, `equity` #006D97 5.78, `fixed-income` #893608 8.09, `gold` #919605 3.20, `cash` #BF74D2 3.16, `government-bond` #34A085 3.22, `miscellaneous` and `chart-other` #808B95 3.47; Dark, #006D97 3.01, #AE450A 3.03, #919605 5.44, #BB6BCF 5.07, #37AA8E 6.05, #999999 6.11. All pass 3:1, all at 100% alpha. three fall under 3:1, as the bar's own segments already do on that surface; the label and % beside each swatch carry the meaning ( R5). The track `chart-empty` is #EBECEE Light, #333333 Dark; the skeleton track `skeleton-background` is #E6E8EA Light, #262626 Dark.
