# Toggle

> Core's Toggle, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

no fill. The kit's `Toggle - Switch` no longer appears in any Toggle variant.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Style` | Default · Toggle only | Title and Detail shown, or the switch alone |
| `State` | Enabled · Pressed · Disabled · Read-only · Skeleton | colours; Read-only's outline track; Skeleton's shape |
| `Toggled` | True · False | thumb at the end (`MAX`) or start (`MIN`); on or off track |

Properties: `Title`, `Label` (BOOLEAN); `Title Text`, `Label Text` (TEXT), on `Style=Default`. 2 × 5 × 2 × 2 = **40 variants**.

Panel order isn't set by the plugin API. Live today: `State` is `Enabled · Disabled · Read-only · Skeleton · Pressed` and `iOS` is `False · True` (and `False · True` on `_Toggle Item`). The order above is the owner's drag in the panel.

## Usage

- `Style=Default` for a setting with a title in a form or list; `Toggle only` where the row already names it (banners, a List item's trailing Toggle).
- Pin `iOS` (ADR 0005).
- The Toggle changes a setting at once. For a choice confirmed by a button, use Checkbox.
- Don't use Read-only for "not available yet": that's Disabled.
