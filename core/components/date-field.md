# Date field

> Core's Date field, compiled for the web: the `iOS=False` look at the Large text size. Generated by the Core sync; do not edit.

## Anatomy and layer tree

Text field's tree ([text-field.md](text-field.md)) without `_Unit suffix`, plus `Calendar`, an Icons instance (`calendar`), last in `Field` after `Status`, as Password field's `Eye`. The base holds every layer the States use (all four `Status` glyphs, every `Detail` line, `Skeleton title`); the spec's `visible` rules pick them per State, since this set is built fresh rather than edited in place.

## Axes

| Axis | Values (default first) | Drives |
| --- | --- | --- |
| `Text filled` | False · True | the value ("17/11/2026") or Placeholder text ("dd/mm/yyyy") |
| `State` | Enabled · Pressed · Focus · Active · Error · Success · Incomplete · Warning · Complete · Read-only · Loading · Disabled · Skeleton | as Text field |
| `Size` | Large · Medium · Small | as Text field (56 · 48 · 36) |

Properties: `Helper` (BOOLEAN, on), as Text field. 2 × 13 × 3 = **78 variants**.

## Component variables and Theme tokens

Text field's: the spec sets `variablePrefix: 'Text field'` and binds the same `Components/Text field/*` variables and Semantic `Theme` tokens per State, as Password field does. No `Date field/*` variables. Its own bindings: the calendar's `Color` on `Theme/Icon/icon-primary`, `Theme/Icon/icon-disabled` when Disabled.

## Icon records

As Text field. The calendar takes the eye's glyph step (`large` on Large, `medium` on Medium and Small).

## Text styles, wrapping and truncation

As Text field, without the `_Unit suffix` row.

## Hit target and Skeleton

- **Hit target**: None, as Text field: the field is a text input; the calendar icon is decoration, not a button (Carbon's).
- **Skeleton**: as Text field.

## Motion

As Text field.

## Accessibility

As Text field, items 1–8; the calendar icon is a non-text pair with the Field (`contrast` in the spec). Item 9:

|  | Web |
| --- | --- |
| Role | `<input type="text" inputmode="numeric">` with a `<label for>` |
| Accessible name | the Title (`<label>`) |
| Announced states | as Text field; the format in `aria-describedby` |
| Focus order | same |

## Usage

- A date typed as text, where the person knows it (a birth date): Date field alone. A date picked from a month: Date picker, which opens a calendar under it.
- Not on iOS: use Date and time - Collapsed.
