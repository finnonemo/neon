# Screen templates

> Core's Screen templates, compiled for the web: the Areas of a screen, and the layouts by breakpoint. Generated by Core's Web compile; do not edit.

## Areas

Every template has the same tree. An Area that a breakpoint doesn't use is hidden, never deleted, so a page component placed once survives a switch of template.

```
<Device or breakpoint>            frame, the screen size
└─ Screen                         HORIZONTAL
   ├─ Sidebar View                spacer: the width Navigation's Sidebar draws over
   ├─ Content View                the main column
   │  └─ Content  ▸ Toolbar · Content Area · Bottom Navigation (a 96-high spacer)
   ├─ Inspector View              the detail column
   │  └─ Inspector ▸ Toolbar · Content Area
   └─ Navigation                  absolute, over Screen: Bottom, Sidebar, Top or Rail by mode
```

| Area | Holds | Filled by |
| --- | --- | --- |
| Status bar | the system bar | none on web |
| Sidebar View | room for the Sidebar at Regular width (a spacer, no fill) |  |
| Content ▸ Toolbar | title and actions of the main column | [Toolbar - Top](../components/toolbars.md) |
| Content ▸ Content Area | **the page component** |  |
| Content ▸ Bottom Navigation | room for the tab bar at Compact width (a spacer, Fill × 96, no fill) |  |
| Inspector ▸ Toolbar | title and actions of the detail column | Toolbar - Top |
| Inspector ▸ Content Area | **a second page component**: the detail of what Content lists |  |

## Width class

Regular width starts where a template hides Bottom Navigation; below it is Compact width, which shows it.

| Platform | Compact width | Regular width |
| --- | --- | --- |
| Web | SM 320 – 499 | MD 500 and up (Sidebar 64 from MD, wider from XL) |

## Layouts

Five layouts, one web section each. A layout says which Areas the screen uses and how wide each is per breakpoint.

| Breakpoint | Simple | Content | Detailed | Multi-column | Immersive |
| --- | --- | --- | --- | --- | --- |
| SM 320 · 499 | Content + BottomNav | Content + BottomNav | Inspector only | Content 2000 + BottomNav | Content + BottomNav |
| MD 500 · 987 | Sidebar 64 · Content | Sidebar 64 · Content | Sidebar 64 · Content · Inspector (Content and Inspector share the rest, 218 each at 500, R13) | Sidebar 64 · Content 2000 | Content |
| LG 988 · 1079 | Sidebar 64 · Content | Sidebar 64 · Content · Inspector 360 | Sidebar 64 · Content 360 · Inspector | Sidebar 64 · Content 2000 | Content |
| XL 1080 · 1271 | Sidebar 240 · Content | Sidebar 240 · Content · Inspector 360 | Sidebar 240 · Content 360 · Inspector | Sidebar 240 · Content 2240 | Content |
| XXL 1272 · 1439 | Sidebar 320 · Content | Sidebar 320 · Content · Inspector 360 | Sidebar 320 · Content 360 · Inspector | Sidebar 320 · Content 2240 | Content |
| XXXL 1440 | Sidebar 320 · Content | Sidebar 320 · Content · Inspector 400 | Sidebar 360 · Content 400 · Inspector | Sidebar 320 · Content 2520 | Content |
| Max 1920 · 2560 · 3840 | Sidebar 320 · Content | Sidebar 320 · Content · Inspector 560 | Sidebar 360 · Content 560 · Inspector | Sidebar 320 · Content 3480 | Content, max 1440 |

- **Simple**: one page. **Content**: a list in Content, its detail in Inspector from LG. **Detailed**: the detail is the main page (Inspector), its list joins from LG. **Multi-column**: Content scrolls sideways (a board or wide table). **Immersive**: no navigation from MD (a flow, a full-screen chart).
- **Readable width**: on Simple, Content and Detailed the `Content` and `Inspector` columns stop at 980 (`Layout/Readable max-width`) and their View centres them, so a wider screen shows an empty band each side. Immersive and Multi-column's board have none.
